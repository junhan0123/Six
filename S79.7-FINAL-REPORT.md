## 4. Root Cause Analysis

### Why server.py fails to import
The server.py expects a module structure that doesn't exist:
1. `import server_handlers` — module doesn't exist
2. `from server_handlers import SystemMixin, ...` — mixin names may differ
3. `capability_os.discovery` — missing module

### Why capability_os fails
The `__init__.py` imports from modules that don't exist:
- `from .verification import (...)` — created stub, but needs more exports
- `from .discovery import (...)` — **MISSING**
