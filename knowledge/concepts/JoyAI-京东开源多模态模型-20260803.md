# JoyAI - 京东开源多模态模型系列

## 简介

**JoyAI** 是京东（JD.com）开源的多模态大模型系列，涵盖图像理解、图像生成、图像编辑、视频交互和长视频生成。

GitHub 组织：`jd-opensource/JoyAI`

## 模型系列

### 1. JoyAI-Image
- **功能**：图像理解 + 文生图 + 指令引导的图像编辑
- **架构**：8B MLLM（多模态大语言模型）+ 16B MMDiT（多模态扩散Transformer）
- **核心**：理解、生成、编辑的闭环协作
- **GitHub**：[jd-opensource/JoyAI-Image](https://github.com/jd-opensource/JoyAI-Image)

### 2. JoyAI-VL-Interaction
- **功能**：实时视频-语言交互系统
- **规模**：8B，视觉优先交互模型
- **特点**：
  - 摄像头/直播流实时识别和对话
  - 400万+时间对齐视频片段训练
  - 强化学习优化
  - 完整训练配方和数据开源
- **GitHub**：[jd-opensource/JoyAI-VL-Interaction](https://github.com/jd-opensource/JoyAI-VL-Interaction)

### 3. JoyAI-Echo
- **功能**：长视频生成
- **模型**：Gemma-3-12B 文本编码器
- **特点**：
  - 超越 Wan 2.6（短视频专家）
  - 对话式实时编辑
  - 轻量超分辨率模块
  - 分布匹配蒸馏加速 7.5x
- **HuggingFace**：[jdopensource/JoyAI-Echo](https://huggingface.co/jdopensource/JoyAI-Echo)
- **GitHub**：[jd-opensource/JoyAI-Echo](https://github.com/jd-opensource/JoyAI-Echo)

## 与 Agnes AI 对比

| 特性 | JoyAI | Agnes AI |
|------|-------|----------|
| 厂商 | 京东 | 独立公司 |
| 部署方式 | 本地部署 | 云端API |
| 能力范围 | 图像/视频为主 | 文本+图像+视频全模态 |
| 文本能力 | 弱（依赖Gemma等） | 强（agnes-2.5-flash等） |
| 易用性 | 需要部署配置 | 开箱即用 |
| 成本 | 硬件成本 | API费用（有免费额度） |
| 开源程度 | 完全开源 | API部分开源 |

## 适用场景

- **实时视频交互**：JoyAI-VL-Interaction 可用于机器人视觉、智能监控
- **长视频生成**：JoyAI-Echo 适合短视频创作、广告素材
- **图像理解+编辑**：JoyAI-Image 适合产品设计、内容创作
- **本地部署**：需要本地化方案且有一定硬件资源
