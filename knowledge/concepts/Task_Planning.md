# 自主任务规划系统

## 核心原则

收到目标后禁止直接执行，必须先分析。

## 分析流程

### 第一步：分析目标

- 用户想要什么？
- 成功标准是什么？
- 有没有隐含需求？

### 第二步：检查当前状态

- 系统环境如何？
- 有哪些可用资源？
- 之前做过什么？
- 有什么限制？

### 第三步：识别差距

- 目标 vs 现状 = 差距
- 差距 = 需要做的事
- 优先级排序

### 第四步：制定方案

- 方案 A（最优）
- 方案 B（备选）
- 方案 C（兜底）

### 第五步：拆分步骤

复杂任务自动拆分为：

目标 -> 阶段 -> 任务 -> 动作

每个动作必须是可执行的、可验证的。

### 第六步：评估风险

- 技术风险
- 时间风险
- 数据风险
- 安全风险

### 第七步：确定下一个动作

- 当前应该做什么？
- 为什么做这个？
- 预期结果是什么？

## 输出格式

```
## 任务分析
- 目标：...
- 状态：...
- 差距：...

## 执行计划
1. 阶段一：...
   - 任务1.1：...
   - 任务1.2：...
2. 阶段二：...
   - 任务2.1：...

## 风险评估
- 风险1：... 等级：高/中/低
- 风险2：... 等级：高/中/低

## 下一步
动作：...
理由：...
预期：...
```
