# Awesome LLM Apps

## 基本信息

- **项目名**: awesome-llm-apps
- **作者**: Shubhamsaboo
- **URL**: https://github.com/Shubhamsaboo/awesome-llm-apps
- **Stars**: 128,734+
- **语言**: Python
- **许可证**: Apache-2.0
- **描述**: 100+ AI Agents、Agent Skills 和 RAG 应用的开源合集，全部经过端到端测试，免费开源

## 项目定位

这是一个**AI 应用模板库**，提供 100+ 个开箱即用的 AI Agent 和 RAG 应用模板。所有项目都经过端到端测试，支持 Claude、Gemini、GPT、DeepSeek、Llama、Qwen 等主流模型。

核心口号："Clone it, ship it, sell it - 100% free and open-source"

## 分类体系

### 🧩 Agent Skills（Agent 技能）
给编码 Agent 新增能力，一条命令安装，自然语言使用。支持 Claude Code、Codex、Cursor 等。
- ⚰️ Project Graveyard — 分析废弃项目，找出死因，帮助完成值得继续的项目
- 🔭 Scope Creep Detector — 检查代码变更是否超出意图
- 🏺 Commit Archaeologist — 从 Git 历史重建代码存在的原因
- 🧠 Advisor Orchestrator Worker — 多模型协作（Claude + GPT + Gemini）
- ♾️ Self-Improving Agent Skills — 自动优化 Agent 技能

### 🌱 Starter AI Agents（入门级 AI Agent）
只需一个 API Key 即可运行的单文件 Agent。
- 🎙️ AI Blog to Podcast — 博客 URL 转播客
- 📊 AI Data Analysis — 用自然语言问 CSV/Excel 问题
- 🩻 AI Medical Imaging — Gemini 医学影像诊断
- 😂 AI Meme Generator — 浏览器驱动生成梗图
- 🎵 AI Music Generator — 提示词生成 MP3
- 🛫 AI Travel Agent — 个性化旅行行程
- ✨ Gemini Multimodal Agent — 视频分析 + 网页搜索
- 🔄 Mixture of Agents — 多 LLM 回答，聚合最佳结果
- 📊 xAI Finance Agent — Grok 实时股票分析
- 🔍 OpenAI Research Agent — 多 Agent 主题研究
- 🕸️ Web Scraping AI Agent — 描述提取目标，Agent 自动抓取

## 使用方式

### 方式一：给编码 Agent 安装技能
```bash
npx skills add https://github.com/Shubhamsaboo/awesome-llm-apps/tree/main/agent_skills/project-graveyard
```

### 方式二：克隆并运行
```bash
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps/starter_ai_agents/ai_travel_agent
pip install -r requirements.txt
streamlit run travel_agent.py
```
