## 二、Homebrew 系统包（196 款）

### 核心开发工具
- **git, git-lfs** — 版本控制
- **gh** — GitHub CLI
- **docker** — 容器化部署
- **colima** — macOS 本地 Docker 运行时
- **lima** — Linux 虚拟机管理
- **node@20, node@22** — Node.js 运行时
- **python@3.12, python@3.13, python@3.14** — Python 多版本
- **pyenv** — Python 版本管理
- **gcc, gmp, mpfr, isl, libmpc** — GCC 编译器链
- **make, cmake (via libtool)** — 构建工具

### 音视频处理
- **ffmpeg** — 音视频编解码（核心工具）
- **imagemagick** — 图像处理
- **sox** — 音频处理
- **lame, opus, vorbis, flac** — 音频编码
- **x264, x265** — 视频编码
- **libvpx, libwebp** — WebP/VP8 视频编码
- **tesseract** — OCR 文字识别
- **openvino** — Intel 推理引擎
- **onnx** — ONNX 模型运行

### 网络与安全
- **curl, aria2** — 下载工具
- **hysteria, sing-box** — 网络加速/代理
- **openssl@3, gnupg, gpgme** — 加密/签名
- **nss, libssh2** — 网络安全库

### 图像处理
- **opencv** — 计算机视觉
- **libheif, libde265, libjpeg-turbo** — 图片格式
- **cairo, pango, poppler** — PDF/图形渲染
- **libxml2, libxslt** — XML 处理

### 其他工具
- **fzf** — 模糊搜索
- **ripgrep** — 快速文本搜索
- **unar, p7zip** — 解压工具
- **sshpass** — SSH 自动化
- **tcl-tk** — Tcl/Tk 运行时
- **synfig** — 2D 动画制作
