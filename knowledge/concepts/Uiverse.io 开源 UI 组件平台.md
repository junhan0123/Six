# Uiverse.io

## 概述
**Uiverse.io** 是一个社区驱动的开源 UI 组件平台，提供大量 CSS 和 Tailwind 样式的 UI 元素。所有组件均可免费使用，采用 MIT 许可证。

## 核心功能
- **组件类型**：按钮、输入框、复选框、卡片、加载动画等
- **技术栈**：纯 CSS 或 Tailwind CSS 实现
- **社区驱动**：用户创建并提交 UI 元素，审核后自动收录
- **开源仓库**：[uiverse-io/galaxy](https://github.com/uiverse-io/galaxy)（12k+ stars）
- **组件数量**：3500+ 个 UI 元素
- **分类**：11 个类别

## 使用方式
1. 访问 [uiverse.io](https://uiverse.io) 浏览和搜索组件
2. 复制 HTML + CSS 代码到项目中使用
3. 遵守 MIT 许可证要求（保留版权声明）

## 贡献流程
1. 创建 UI 元素
2. 提交到 Uiverse.io
3. 审核通过后自动上传到 GitHub 仓库

## 技术特点
- 每个组件都是自包含的 HTML 文件
- 可直接复制使用
- 支持自定义和修改
- 社区审核保证质量

## 相关资源
- 官网：https://uiverse.io

## 应用场景
- 快速原型开发
- 寻找灵感
- 学习 CSS/Tailwind 技巧
- 个人项目快速搭建 UI

## 注意事项
- Cloudflare 防护较严格，可能需要代理访问
- 使用时需保留原作者和 Uiverse.io 的版权声明
- 组件质量因贡献者而异，建议审查代码
