# OSIRIS - 开源全球情报平台

## 简介

**OSIRIS** 是一个生产级的开源开源情报（OSINT）平台，提供实时全球态势感知仪表盘。定位为**开源版 Palantir**。

- **GitHub**: [simplifaisoul/osiris](https://github.com/simplifaisoul/osiris)
- **⭐**: 7400+
- **Forks**: 1500+
- **License**: MIT
- **创建**: 2026-05-12
- **语言**: TypeScript
- **Live Demo**: [osirisai.live](https://osirisai.live)
- **Discord**: [加入](https://discord.gg/umBykEpb98)

## 核心功能

### 16 层数据可视化

| 数据层 | 数据源 |
|--------|--------|
| 航空追踪 | 商业/私人/军用/私人飞机 — OpenSky Network |
| 海事监控 | 39个全球港口、10个咽喉要道 — 静态海军情报 |
| CCTV 监控 | 2000+ 摄像头 — TfL, WSDOT, Caltrans, NYC DOT |
| 地震监测 | 实时 M2.5+ — USGS Earthquake API |
| 火灾热点 | 实时监测 — NASA FIRMS |
| 新闻直播 | 25+ 全球电视台 24/7 — NBC, CBS, Sky News, Al Jazeera |
| 天气事件 | 严重天气 — NASA EONET |
| 太空天气 | 太阳风暴、卫星 — NOAA SWPC, N2YO |
| 网络安全 | CVE 威胁、漏洞扫描 — NVD |
| 冲突区域 | 13个活跃冲突区 |
| 加密货币 | BTC+ETH 钱包追踪、OFAC SDN 匹配 |
| 制裁查询 | 人员/组织/船只 SDN 搜索 — OpenSanctions |
| Telegram OSINT | 公开频道地理标记帖子 |

### 冲突区域监控

**活跃战争**：乌克兰、加沙、苏丹、缅甸、刚果（金）、也门
**高度紧张**：叙利亚、黎巴嫩、萨赫勒、索马里、红海
**紧张升级**：台湾海峡、朝鲜非军事区

### RECON 工具包

- **端口扫描** — TCP 连接扫描 + 服务指纹识别
- **DNS 查询** — A, AAAA, MX, NS, TXT, CNAME 全记录
- **WHOIS** — 域名/IP 注册信息（自动交叉检查 OFAC SDN）
- **SSL/TLS 检查** — 证书链分析
- **IP 情报** — 地理位置、ASN、威胁声誉
- **漏洞扫描** — CVE 查询 NVD 数据库
- **加密货币钱包追踪** — BTC+ETH 余额、交易历史、OFAC 制裁标记
- **OFAC 制裁搜索** — 人员/组织/船只/飞机制裁名单查询

### Telegram OSINT 层

- 从 `t.me/s/<channel>` 抓取公开频道帖子
- 无需 Bot API Token，无需 MTProto
- 多语言地名解析（英文+西里尔字母+阿拉伯文）
- 地理标记后绘制在地图上

### 加密货币情报

- **BTC** — blockstream.info Esplora API（无需 Key）
- **ETH** — Blockscout 公开实例（无需 Key）
- 自动交叉检查 OFAC SDN 制裁地址列表
- 制裁钱包显示红色 **SANCTIONED — OFAC SDN** 标记

## 部署方式

### 本地开发

```bash
git clone https://github.com/simplifaisoul/osiris.git
cd osiris
npm install
npm run dev
# 访问 http://localhost:3000
```

### Docker 部署

```bash
git clone https://github.com/simplifaisoul/osiris.git
cd osiris
cp .env.template .env
docker compose up -d
```

### 预构建镜像

```bash
docker pull ghcr.io/simplifaisoul/osiris:latest
docker run -d -p 3000:3000 --env-file .env ghcr.io/simplifaisoul/osiris:latest
```

### CasaOS 一键部署

docker-compose.yml 内置 CasaOS 元数据，支持 CasaOS 一键安装。

## 环境变量

大部分功能**无需 API Key** 即可运行，所有核心数据源都是公开的。

```env
# 端口（容器内始终 3000，通过此变量改映射端口）
OSIRIS_PORT=3000

# RECON 扫描器后端（唯一必需的配置）
SCANNER_URL=
SCANNER_KEY=

# 可选（更高速率限制）
FIRMS_API_KEY=                # NASA FIRMS
OPENSKY_CLIENT_ID=            # OpenSky OAuth2
OPENSKY_CLIENT_SECRET=
N2YO_API_KEY=                 # N2YO 卫星
AIS_API_KEY=                  # aisstream.io 海事
```

> 不配置 `SCANNER_URL`/`SCANNER_KEY` 时 RECON 工具返回 503，其他功能正常。

## 性能优化

- 相比初版 **减少 75% 的边缘请求**
- 激进轮询放松（稳定数据 15-30 分钟间隔）
- 静态数据内存缓存（新闻源零外部 API 调用）
- `layerFetchedRef` 防止重复 API 请求
- 视口感知加载（只加载可见区域数据）
