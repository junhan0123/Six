# AI 视频生成管线设计与质量优化

> 对应 Hermes 技能：`ai-video-pipeline`

## 概述

AI 视频生成管线设计与质量优化是一套完整的视频生成工作流方法论，覆盖从底图生成到最终视频输出的全流程。

## 管线架构

```
底图生成 → 图生视频 → 配音合成 → 剪辑合成 → 输出
```

## 核心环节

### 1. 底图生成
- 使用 ComfyUI + FLUX/SDXL 模型
- 提示词工程：正向词 + 负面词 + 参数配置
- 高清修复：Real-ESRGAN 4 倍超分辨率

### 2. 图生视频
- 使用 Agnes AI、WAN 2.2 等模型
- 控制视频长度、帧率、分辨率
- 首尾帧控制确保连贯性

### 3. 配音合成
- Edge TTS（云端免费）
- ChatTTS（本地开源）
- 音色克隆支持

### 4. 剪辑合成
- FFmpeg 命令行处理
- 字幕叠加、转场效果
- 多轨道音频混音

## 质量优化要点

1. **底图质量**：高分辨率、清晰构图是基础
2. **视频连贯性**：首尾帧控制、帧率匹配
3. **音画同步**：配音时长与视频时长匹配
4. **输出格式**：根据平台要求调整编码参数
