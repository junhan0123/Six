## 二、GUI 开源剪辑软件

### 2.1 Shotcut

- **协议**：MIT License（最宽松）
- **技术栈**：C++ / Qt / MLT 多媒体框架
- **特点**：跨平台非线性编辑器，支持命令行批处理、插件扩展
- **底层**：基于 MLT 框架，可直接调用 FFmpeg 进行编码
- **安装**：`brew install --cask shotcut`

### 2.2 Kdenlive

- **协议**：GPL-3.0
- **技术栈**：C++ / Qt / KDE Frameworks / MLT
- **特点**：功能完整（多轨道、关键帧、效果链），适合复杂时间轴自动化
- **底层**：共享 MLT + FFmpeg 编解码基础设施
- **安装**：`brew install --cask kdenlive`

### 2.3 OpenShot

- **协议**：GPL-3.0
- **技术栈**：Python / GTK / libmlt
- **特点**：轻量级，API 友好，适合快速原型与自动化脚本开发
- **安装**：`brew install --cask openshot`

### 2.4 Avidemux

- **协议**：GPL-2.0
- **技术栈**：C++
- **特点**：专注格式转换、简单剪辑、字幕硬烧，CLI 交互成熟
- **脚本模式**：`--load` + `--save` 支持批量自动化
- **安装**：`brew install --cask avidemux`

## 四、技术架构对比

| 维度 | GUI 软件 | AI 自动化项目 |
|------|----------|---------------|
| **核心引擎** | MLT / FFmpeg | FFmpeg + AI 模型 |
| **自动化程度** | 手动操作为主 | 全自动流水线 |
| **AI 能力** | 无或基础 | 深度集成（Whisper/Vision/GPT） |
| **CLI 支持** | 部分支持 | 原生 CLI / API |
| **Agent 集成** | 困难 | 原生支持 |
| **适用场景** | 精细手动剪辑 | 批量/重复性剪辑 |

## 五、与本机 FFmpeg 的集成路径

本机已部署 `ffmpeg` + `ImageMagick`，可构建以下自动化管线：

1. **素材分析**：`ffprobe` 提取元数据，时长/分辨率/码率
2. **语音处理**：Whisper 提取字幕（SRT）
3. **智能切分**：基于静音检测 / 场景切换自动切分
4. **转码拼接**：FFmpeg 多段拼接、格式转换
5. **画面处理**：ImageMagick 批量帧处理（水印/缩放/调色）
6. **配音合成**：Edge-TTS / IndexTTS 生成配音
7. **最终合成**：FFmpeg 字幕硬烧 + 音画同步
