## 二、项目对比

| 维度 | CLI-Anything | UI-TARS-desktop |

| 定位 | CLI Agent / 软件原生化 | GUI Agent / 桌面应用 |

## 三、已知问题

1. **网络 SSL 阻断**：外网 DNS/SSL/TCP 完全阻断，`cli-hub` 内置的 registry/matrix 拉取命令触发 `SSLCertVerificationError`
2. **系统 Python 版本**：macOS 自带 Python 3.9.6，不满足 CLI-Anything 的 >=3.10 要求，需使用 pyenv 切换至 3.11.15
3. **UI-TARS-desktop 未安装**：需确认 Node.js 环境后再安装
