# 麦香岁月 - Art Standard

## 视觉定位

河南农村生活气息，温暖质朴的像素风格。贴近真实乡村风貌，避免过度美化或卡通化。

## 像素规格

| 参数 | 值 |
|------|-----|
| 基础像素网格 | 1px = 1 unit |
| 渲染缩放 | 整数倍缩放（2x / 4x） |
| 抗锯齿 | 关闭，保持像素锐利 |

## Sprite 尺寸

| 类型 | 尺寸 |
|------|------|
| 角色 | 16×24 px（含阴影） |
| 小道具 | 8×8 ~ 16×16 px |
| 大道具 | 16×32 ~ 32×32 px |
| NPC | 同角色标准 |

## Tile 尺寸

| 类型 | 尺寸 |
|------|------|
| 地面 Tile | 16×16 px |
| 建筑 Tile | 32×32 px |
| 装饰 Tile | 16×16 px |

## 色彩规范

- 主色调：暖黄、土褐、青绿
- 饱和度：中等偏低，偏复古
- 对比度：柔和，避免高反差
- 光影：固定方向光源，简单投影

## 美术生成原则

1. **写实优先**：参考河南农村真实场景和物件
2. **像素清晰**：每个元素在缩放后可辨识
3. **统一风格**：所有资产使用相同调色板和绘制规范
4. **功能导向**：美术服务于玩法，不追求纯装饰
5. **可复用**：Tile 和 Sprite 尽量模块化组合
