# 技术决策：自研 AI 智能体平台而非基于 Dify

## 决策背景

客户需要一套面向外部用户的智能体平台。经过评估，决定自研而非基于 Dify 二次开发。

## 决策依据

### 为什么不用 Dify

| 维度 | Dify | 自研 |
|------|------|------|
| **License** | Other（非标准开源协议），商业交付有合规风险 | 完全自主，协议可控 |
| **架构控制** | 黑盒，定制受限 | 完全可控 |
| **技术栈统一** | Next.js + Python，与小6不同 | Vue3 + Python，与小6统一 |
| **能力复用** | 无法复用小6的能力模块系统 | 直接复用 |
| **长期成本** | 二次开发可能比自研更复杂 | 一次投入，长期收益 |

### 自研优势

1. **License 无限制**：商业交付无合规风险
2. **架构完全可控**：按需定制，不受上游限制
3. **技术栈统一**：与小6项目共用 Vue3 + Python 后端
4. **能力模块复用**：小6的能力模块系统可直接用于平台
5. **长期成本更优**：一次投入，长期收益

## 核心开发模块

### 第一阶段（MVP）

1. **多模型适配层**
   - 统一接口适配 DeepSeek、通义千问、Ollama、Agnes AI
   - OpenAI 兼容格式作为标准接口

2. **多租户 + 权限管理**
   - 租户隔离
   - 角色权限（管理员、开发者、普通用户）
   - API Key 管理

3. **核心对话引擎**
   - 基于小6的核心对话系统
   - 支持多轮对话、上下文管理

### 第二阶段（RAG + 工作流）

4. **RAG 管线**
   - 文档解析（PDF、PPT、Word 等）
   - 文本切分与向量化
   - 检索与权限过滤

5. **工作流引擎**
   - 可视化流程编排
   - 顺序执行、条件分支、工具调用
   - 人工确认节点

### 第三阶段（运维 + 安全）

6. **异步任务系统**
   - 任务队列
   - 日志记录
   - 错误重试

7. **安全沙箱**
   - 密钥保护（加密存储）
   - 输入审核
   - 代码执行沙箱

## 与小6项目的关系

|------|---------|---------|

| 能力模块 | ✅ 已有 | 复用 + 扩展 |
| 多租户 | ❌ | 新增 |
| RAG 管线 | ❌ | 新增 |
| 工作流引擎 | ❌ | 新增 |
| 异步任务 | ❌ | 新增 |

## 技术栈建议

| 组件 | 技术 | 理由 |
|------|------|------|
| 前端 | Vue3 + Vite | 与小6统一 |
| 后端 | Python (FastAPI) | 与小6统一 |
| 数据库 | PostgreSQL | 多租户隔离 |
| 缓存 | Redis | 会话、队列 |
| 向量数据库 | Qdrant / Milvus | RAG 检索 |
| 任务队列 | Celery / RQ | 异步任务 |
| 部署 | Docker Compose | 快速部署 |
