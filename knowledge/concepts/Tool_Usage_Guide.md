# 工具使用指南

## 核心原则

1. 工具优先，不凭空猜测
2. 真实输出，不编造结果
3. 并行调用，提高效率
4. 失败重试，不超过3次

## 文件操作

### read_file
- 用途：读取文件内容（替代 cat/head/tail）
- 输入：文件路径、起始行、行数
- 输出：带行号的文件内容
- 提示：支持相对路径、绝对路径、~路径

### write_file
- 用途：创建或覆盖文件（替代 echo/cat）
- 输入：文件路径、内容
- 输出：写入结果
- 提示：自动创建父目录

### patch
- 用途：精准编辑文件（替代 sed/awk）
- 输入：文件路径、旧文本、新文本
- 输出：编辑结果
- 提示：使用模糊匹配，容错性强

### search_files
- 用途：搜索文件内容（替代 grep）
- 输入：正则表达式、路径、文件过滤
- 输出：匹配结果
- 提示：支持内容搜索和文件名搜索

## 终端操作

### terminal
- 用途：执行 Shell 命令
- 输入：命令、超时、工作目录
- 输出：命令输出
- 提示：前台默认，后台需设置 notify

## 搜索操作

### web_search
- 用途：网络搜索
- 输入：查询字符串
- 输出：搜索结果列表

### web_extract
- 用途：提取网页内容
- 输入：URL 列表
- 输出：清理后的 Markdown 内容

### session_search
- 用途：搜索历史会话
- 输入：查询、会话ID、窗口
- 输出：会话消息

## 自动化操作

### computer_use
- 用途：控制桌面
- 输入：动作、元素索引
- 输出：操作结果
- 提示：优先使用 SOM 模式

### delegate_task
- 用途：委派子任务
- 输入：目标、上下文
- 输出：子任务结果

### cronjob
- 用途：创建定时任务
- 输入：动作、调度、提示词
- 输出：任务状态

## 失败处理

1. 记录失败原因
2. 尝试替代方案
3. 不超过3次重试
4. 失败后立即停止并报告
