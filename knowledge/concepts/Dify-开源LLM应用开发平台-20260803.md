# Dify - 开源 LLM 应用开发平台

## 简介

**Dify** 是一个开源的 LLM 应用开发平台，提供可视化界面整合 AI 工作流、RAG 管线、Agent 能力、模型管理和可观测性功能，帮助团队快速从原型到生产。

- **GitHub**: [langgenius/dify](https://github.com/langgenius/dify)
- **⭐**: 151,218
- **Forks**: 23,864
- **License**: Other（非标准开源协议）
- **语言**: TypeScript + Python
- **创建**: 2023-04-12
- **大小**: 465 MB
- **官网**: [dify.ai](https://dify.ai)

## 核心定位

Dify 定位为**AI 应用开发平台**——可视化搭建 AI 应用、工作流、RAG 问答系统、Agent 应用等，从原型到生产一站式解决。

## 七大核心功能

### 1. Workflow（工作流）
- 可视化画布构建 AI 工作流
- 支持条件分支、循环、并行等复杂逻辑
- 可复用节点和模块

### 2. Comprehensive Model Support（全面模型支持）
- 集成数百个闭源/开源 LLM
- 支持数十个推理提供商和自托管方案
- 覆盖 GPT、Mistral、Llama3 和所有 OpenAI API 兼容模型
- 支持多模型切换和路由

### 3. Prompt IDE（提示词编辑器）
- 直观界面编写和调试 Prompt
- 多模型性能对比
- 支持添加 TTS、图片生成等附加功能
- 支持聊天型应用的快速原型

### 4. RAG Pipeline（检索增强生成管线）
- 完整 RAG 能力覆盖
- 文档摄取 → 文本提取 → 分块 → 嵌入 → 检索
- 内置 PDF、PPT 等常见格式文本提取
- 支持多种向量数据库

### 5. Agent（智能体）
- 基于 Function Calling 或 ReAct 定义 Agent
- 50+ 内置工具：Google Search、DALL·E、Stable Diffusion、WolframAlpha 等
- 支持自定义工具扩展
- 可配置工具调用策略

### 6. LLMOps（可观测性）
- 应用日志监控和分析
- 性能指标追踪
- 基于生产数据和标注持续优化
- 支持 Opik、Langfuse、Arize Phoenix 集成

### 7. Backend-as-a-Service（后端即服务）
- 所有功能都提供对应 API
- 可轻松嵌入自有业务逻辑
- 支持多租户和权限管理

## 部署方式

### 方式一：Dify Cloud（推荐试用）
- 官方托管服务，零配置
- 沙盒计划含 200 次免费 GPT-4 调用
- 功能与自托管版本一致
- 地址：[cloud.dify.ai](https://cloud.dify.ai)

### 方式二：自托管（社区版）
```bash
cd dify
cd docker
cp .env.example .env
docker compose up -d
```
- 最低配置：2 核 CPU + 4GB 内存
- 访问 `http://localhost/install` 完成初始化

### 方式三：企业版
- 额外提供企业级功能
- 需联系商务：business@dify.ai

### 方式四：Kubernetes
- 社区提供 Helm Chart 和 YAML 文件
- 支持高可用部署

- **小6**：作为智能中枢，调度 Dify 创建的应用作为能力模块

## 适用场景

## 限制与注意事项

1. **License**：使用 Other 协议（非标准开源），商业使用需确认
2. **自托管复杂度**：虽然 Docker 一键部署，但生产环境需要配置向量数据库、缓存等
3. **模型依赖**：部分高级功能依赖闭源模型（GPT-4 等）
4. **社区规模**：151k⭐，社区活跃，但中文文档相对有限
