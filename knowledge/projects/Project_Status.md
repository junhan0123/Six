# 项目状态管理

## 核心能力

自动维护项目状态与进度。

## 状态要素

### 项目列表

- 项目名称
- 技术栈
- 当前阶段
- 最后更新时间

### 项目状态

- 进行中
- 暂停
- 已完成
- 已废弃

### 任务进度

- 总任务数
- 已完成
- 进行中
- 待开始

### 技术债

- 已知问题
- 待优化项
- 待重构模块

### 风险

- 技术风险
- 时间风险
- 资源风险

## 检查流程

1. 扫描项目目录
2. 读取项目文件
3. 分析代码结构
4. 更新状态记录
5. 生成健康报告

## 输出格式

项目健康报告：

```
项目：[名称]
状态：[状态]
最近变化：[描述]
问题：[列表]
建议：[列表]
```
