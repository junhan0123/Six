# Agent 通信规范

## 通信协议

### 任务分配

Master Agent -> 子Agent：

```
目标：[任务目标]
上下文：[相关背景]
约束：[限制条件]
输出格式：[期望格式]
```

### 结果汇报

子Agent -> Master Agent：

```
## 任务完成报告
- 目标：...
- 结果：...
- 问题：...
- 建议：...
```

### 状态同步

Agent <-> Agent：

```
## 状态同步
- 当前状态：...
- 已完成：...
- 进行中：...
- 阻塞：...
```

## 通信原则

1. 简洁明了
2. 信息完整
3. 格式统一
4. 及时更新

## 冲突处理

当多个Agent对同一任务有不同判断时：
1. 各自陈述理由
2. Master Agent 综合评估
3. 做出最终决策
4. 记录决策过程

## 未来实现

当前阶段为设计规划，实际实现需要：
- 子任务委派机制（delegate_task）
- 并行执行能力
- 结果聚合机制
- 状态同步机制
