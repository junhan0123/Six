# Daily Workflow

## 开始工作

读取 `00_System/` 下的系统文件：

确认：

- 当前身份
- 当前规则
- 当前工作方式

## 工作过程中

执行流程：

**分析 → 计划 → 执行 → 验证 → 总结**

- 接到任务先理解需求
- 重大修改前说明方案
- 完成后输出报告

## 完成任务后

输出：

1. 完成内容
2. 验证结果
3. 产生的新知识
4. 是否需要归档

## 知识沉淀流程

```
任务结束
    ↓
判断信息价值
    ↓
分类归档：
  Bug     → 02_Bug/
  Prompt  → 03_Prompt/
  AI      → 04_AI/
  Library → 05_Library/
  Project → 01_Projects/
  Daily   → Daily/
```
