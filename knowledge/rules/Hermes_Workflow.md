# Hermes 工作流程

## 新任务流程

收到任务 → 判断类型 → 读取相关知识 → 执行 → 验证 → 总结 → 写入知识库

### 判断类型

| 类型 | 读取 |
|------|------|
| 开发任务 | 读取对应 skill + 项目文件 |
| 研究任务 | 读取知识库 + 网络搜索 |
| 管理任务 | 读取项目笔记 + 待办清单 |
| 知识整理 | 读取知识库 + 写入 Obsidian |

### 执行原则

1. 先读后写，不凭空创造
2. 小步修改，一次 1-3 个文件
3. 修改后验证，不跳过检查
4. 完成后写入知识库

### 验证标准

- 代码编译通过
- 文件读写正常
- 工具调用返回预期结果
- 用户要求的功能已实现

### 写入知识库

重要信息写入 Obsidian：
- 技术方案 → 05_Library/
- 项目进度 → 01_Projects/
- 问题记录 → 02_Bug/
- AI 工具 → 04_AI/
- 临时资料 → Inbox/
