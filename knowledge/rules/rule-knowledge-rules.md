# Knowledge Rules

## 目录职责

### 02_Bug

保存：

- 错误原因分析
- 解决方案
- 环境问题排查
- 踩坑记录

### 03_Prompt

保存：

- 已验证有效的 Prompt
- 工作流提示词
- AI 调用模板

### 04_AI

保存：

- AI 工具资料
- 模型资料
- 本地部署方案
- Agent 配置

### 05_Library

保存：

- 技术知识笔记
- 开发经验
- 通用方法论

### Daily

保存：

- 每日工作记录
- 阶段总结

### Inbox

保存：

- 未整理的临时资料

## 判断规则

每次任务结束后自问：**是否产生长期价值？**

- **没有** → 不保存
- **有** → 归档到正确目录
