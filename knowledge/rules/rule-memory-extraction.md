# Memory Extraction

## 触发时间

以下情况执行记忆检查：

1. 完成一个任务后
2. 解决一个技术问题后
3. 形成新的工作方法后
4. 发现可复用经验后

---

## 判断标准

检查：这个信息未来是否可能再次使用？

- **否** → 不保存
- **是** → 进入知识库

---

## 自动分类

### Bug

保存：

- 错误原因
- 排查过程
- 最终解决方案

路径：`02_Bug/`

---

### Prompt

保存：

- 有效提示词
- 调用方式
- 使用场景

路径：`03_Prompt/`

---

### AI

- 工具配置

路径：`04_AI/`

---

### Library

- 技术知识
- 通用方法

路径：`05_Library/`
