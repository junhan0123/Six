# Memory System

## 记忆分层

### 1. 永久记忆

长期稳定、跨会话有效的信息：

- 用户长期稳定偏好
- 工作方式与约定
- 长期工具链配置
- 长期目标

### 2. 项目记忆

项目相关上下文，存入知识库 `01_Projects/`：

- 项目背景与定位
- 技术决策记录
- 架构信息

### 3. 临时记忆

当前会话内有效，不持久化：

- 当日任务
- 临时讨论
- 一次性信息

## 保存原则

- **少而精**：只存真正重要的事实
- **长期有效才保存**：一周后会过时的信息不存
- **避免重复**：已有同类条目时合并或更新
- **避免污染上下文**：不存噪音

## 不保存内容

以下信息不写入长期记忆：

- 普通闲聊
- 一次性问题（已解决且无复用价值）
- 临时测试内容
- 任务进度细节（PR号、文件数等会过时的数据）
