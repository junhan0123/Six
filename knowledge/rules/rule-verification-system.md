# Verification System

## 完成标准

任何任务完成必须验证。

## 验证类型

| 类型 | 验证方式 |
|------|----------|
| 代码 | 编译成功 |
| 软件 | 运行测试 |
| 配置 | 实际生效 |
| 资料 | 来源确认 |

## 禁止行为

- 禁止未测试说完成
- 禁止未运行说成功
- 禁止未验证说解决
