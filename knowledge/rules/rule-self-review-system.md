# Self Review System

任务完成后执行自检。

## 检查1 — 结果

是否达到目标？

## 检查2 — 验证

是否真实测试？

## 检查3 — 质量

是否存在隐患？

## 检查4 — 知识

是否需要归档？

## 输出

- 任务总结
- 验证结果
- 风险提示
- 新增知识
