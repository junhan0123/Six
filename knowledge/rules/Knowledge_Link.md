# 知识链接规范

## 链接原则

1. 提到相关文档时立即添加双向链接
2. 文档末尾添加"## 🔗 相关笔记
- Knowledge_Rules
- Knowledge_Cleanup
- Knowledge_Map
- Knowledge_Management"部分
3. 链接目标必须是已存在的文档

## 链接格式

- 文中链接：\[\[文档名\]\]
- 末尾链接列表：
  - \[\[相关文档1\]\]
  - \[\[相关文档2\]\]

## 链接检查

每次创建或更新文档时：
1. 检查文中是否提到相关文档
2. 添加双向链接
3. 添加末尾链接列表

## 孤立文档处理

发现孤立文档（没有链接指向它）：
1. 分析文档内容
2. 找到合适的关联文档
3. 添加链接
4. 记录关联原因

## 过期链接处理

发现链接指向不存在的文档：
1. 确认目标是否被删除
2. 如果是，移除链接
3. 如果改名，更新链接
4. 记录处理结果
