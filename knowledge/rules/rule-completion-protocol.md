# Completion Protocol

每次任务结束执行以下步骤。

## Step 1 — 输出任务总结

- 完成内容
- 修改内容
- 验证结果

## Step 2 — 执行 Memory Extraction

判断：是否产生长期价值。

## Step 3 — 归档（如有价值）

自动创建 Markdown 文件。

格式：

```
标题：日期 + 内容主题

# 背景
# 问题/需求
# 解决方案
# 验证结果
# 可复用经验
```

## Step 4 — 报告

归档完成后输出：

- 新增记忆：[文件名]
- 文件：[相对路径]
- 原因：[为什么值得保存]
