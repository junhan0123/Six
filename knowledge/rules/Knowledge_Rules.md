# Knowledge Rules

## Memory

保存：

- 永久规则
- 身份
- 偏好
- 行为约束

禁止保存：

- 项目细节
- 技术参数
- 临时问题

## Obsidian

保存：

- 项目
- 技术
- Bug
- 经验
- 方案

## Daily

保存：

- 当天过程

## Inbox

保存：

- 待整理资料
