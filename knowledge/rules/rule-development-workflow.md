# Development Workflow

## 软件开发流程

```
需求
↓
分析代码结构
↓
制定方案
↓
修改
↓
编译
↓
测试
↓
记录
```

## Bug 处理流程

```
发现Bug
↓
复现
↓
分析原因
↓
修复
↓
验证
↓
记录到 02_Bug/
```
