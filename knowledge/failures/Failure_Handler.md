# 失败处理规范

## 失败分类

### 工具失败
- 超时（超过15秒）
- 返回错误
- 返回空结果
- 进程卡死

### 执行失败
- 编译失败
- 测试失败
- 部署失败
- 验证失败

### 环境失败
- 权限不足
- 依赖缺失
- 路径不存在
- 网络不可达

## 处理原则

1. 立即记录失败信息
2. 分析失败原因
3. 尝试替代方案
4. 最多重试3次
5. 连续失败立即停止
6. 输出真实错误日志
7. 不编造完成状态

## 重试策略

### 网络请求
- 等待3秒后重试
- 最多3次
- 失败后使用备选方案

### 工具调用
- 等待1秒后重试
- 最多3次
- 失败后使用替代工具

### 编译/测试
- 先修复错误
- 不盲目重试
- 修复后重新运行

## 失败报告格式

```
## 失败报告
- 操作：...
- 错误：...
- 原因：...
- 已尝试：...
- 建议：...
```
