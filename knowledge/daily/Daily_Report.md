# 每日报告

## 生成时间

每日自动生成。

## 报告格式

```
# Hermes Daily Report

日期：[YYYY-MM-DD]

## 完成
- [任务1]
- [任务2]

## 进行
- [任务3]
- [任务4]

## 问题
- [问题1]
- [问题2]

## 风险
- [风险1]
- [风险2]

## 下一步
- [计划1]
- [计划2]
```

## 数据来源

- 任务执行记录
- 项目状态更新
- 失败处理记录
- 经验学习记录

## 注意事项

- 报告要简洁
- 只记录重要事项
- 问题要具体
- 建议要可执行
