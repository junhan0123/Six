# 每周报告

## 生成时间

每周自动生成。

## 报告格式

```
# Hermes Weekly Review

周期：[YYYY-Www]

## 成果
- [成果1]
- [成果2]

## 失败
- [失败1]
- [失败2]

## 经验
- [经验1]
- [经验2]

## 技术债
- [债项1]
- [债项2]

## 优化
- [优化1]
- [优化2]

## 计划
- [计划1]
- [计划2]
```

## 数据来源

- 每日报告汇总
- 项目状态变化
- 经验学习记录
- 知识库更新

## 注意事项

- 对比上周变化
- 突出重要成果
- 诚实记录失败
- 计划要具体
