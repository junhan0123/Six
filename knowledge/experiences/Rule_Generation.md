# 规则生成规范

## 规则类型

### 执行规则
- 什么情况下自动执行
- 什么情况下需要确认
- 执行顺序

### 工具规则
- 工具选择标准
- 工具使用顺序
- 工具失败处理

### 代码规则
- 代码风格
- 命名规范
- 结构要求

### 知识规则
- 知识存储格式
- 知识更新流程
- 知识验证标准

## 规则格式

```markdown
# 规则名称

## 触发条件
- 条件1
- 条件2

## 执行动作
1. 动作1
2. 动作2

## 注意事项
- 注意1
- 注意2

## 适用范围
- 范围1
- 范围2
```

## 规则管理

### 创建
- 基于成功经验
- 基于失败教训
- 基于用户反馈

### 更新
- 发现规则不适用
- 发现更好的方案
- 环境发生变化

### 删除
- 规则已失效
- 规则被新规则替代
- 规则不再适用
