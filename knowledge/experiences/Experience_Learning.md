# 经验学习系统

## 核心原则

每次重要任务结束后，自动提取经验并转化为知识规则。

## 提取内容

### 成功经验
- 做了什么
- 为什么成功
- 可复用的模式

### 失败原因
- 出了什么问题
- 根本原因
- 如何避免

### 最佳方案
- 当前最优解
- 为什么最优
- 适用场景

### 优化建议
- 可以改进的地方
- 改进方向
- 优先级

## 转化流程

1. 任务完成
2. 自动提取经验
3. 判断是否形成新规则
4. 如果是，写入知识库
5. 更新相关文档

## 规则生成标准

新规则必须满足：
- 至少发生过2次同类问题
- 解决方案已验证有效
- 具有通用性
- 有明确的触发条件

## 输出格式

```
## 经验记录
- 任务：...
- 时间：...
- 结果：成功/失败

## 经验总结
- 成功因素：...
- 失败原因：...
- 最佳方案：...
- 优化建议：...

## 生成的规则
- 规则1：...
- 规则2：...
```
