## 二、核心数据流

### 2.1 用户交互流

```
用户输入
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                     Intent Gateway                             │
│   User Intent → GDE Classification → Goal Decision            │
└─────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                     AgentRuntime                               │
│   PLANNING → EXECUTING → REFLECTING → IDLE                    │
└─────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                     PermissionGuard                            │
│   Plan → Evaluate → Execute → Verify                          │
└─────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                     EventBus                                   │
│   publish_domain() / publish_system()                          │
└─────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────┐
│                     AppState                                   │
│   前端订阅 → 视图更新 → SSE推送                                 │
└─────────────────────────────────────────────────────────────────┘
```

```

    ↓ (周期触发)
```

## 五、架构原则

### 5.1 单一来源纪律

```
✅ 单一状态源: AppState
✅ 单一事件总线: EventBus
✅ 单一权限闸门: PermissionGuard
✅ 单一执行通道: ExecutionChannel
✅ 单一记忆系统: Memory
```

### 5.2 禁止行为

```
❌ 禁止创建第二 EventBus
❌ 禁止创建第二 State
❌ 禁止绕过 PermissionGuard 执行
❌ 禁止跨模块直接调用（必须经 EventBus）
❌ 禁止硬编码事件名
```

### 5.3 Phase 9 新增纪律

```
✅ Scheduler 只负责调度，不执行业务逻辑
✅ Scheduler 只发布事件，不调用 AgentRuntime
✅ Scheduler 只管理任务生命周期
✅ 所有主动行为必须经 PermissionGuard
```
