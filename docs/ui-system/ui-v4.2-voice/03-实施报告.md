## 二、voice-presence.js 关键结构

- **状态机**：`IDLE / LISTENING / PROCESSING / SPEAKING / ERROR`，以 `setVoice(s)` 写入 `#aiCore[data-voice]`。`returnToRest()` 在活动态归位为 LISTENING、否则 IDLE。
- **采集（主路径，复用后端 ASR）**：`getUserMedia` + `MediaRecorder` 取 webm 音频 → 每段 `POST /api/asr?ext=.webm` → `transcribe_bytes`（FunASR/Vosk/Whisper）→ 返回文本。`startSegment()` 以 `SEGMENT_MS=7000` 循环分段，活动态持续听写。
- **降级路径（浏览器原生 STT）**：当 `getUserMedia` 不可用或后端 ASR 返回 err/空 → `SpeechRecognition(lang=zh-CN)` 实时 `interimResults` 转写。保证 Voice Orb 在后端 ASR 缺失环境（本沙箱即如此）仍可用。
- **唤醒触发**：订阅既有 SSE `wakeword_detected`（`zz-events` 已登记），命中且未活动即 `start()`（无接触唤醒）。
- **SPEAKING 联动**：订阅既有 `agent_state`（`V4Data.onAgentState`）；仅当 `voiceDispatchAt` 在 `SPEAK_WINDOW=12000ms` 内（即本次确由语音投出）才点亮 SPEAKING 脉冲（`SPEAK_PULSE=2200ms`），归位时不误伤键入意图。
- **提交**：`commit(text)` → `V4Intent.setText(text)`（实时字幕）→ `V4Intent.submit(text)`（经既有 `ZZIntentGateway.dispatch` → `/api/agent/intent`，与键入同一链路）。
- **交互入口**：`.voice` 点击切换；全局 `Ctrl+Shift+U`（Mac `⌘ShiftU`）切换；二者在输入框聚焦时让行。
- **副文案**：复用既有 `#aiCoreDoing`（`V4Core.setDoing`）显示「我在听，说吧 / 收到，我来处理 / 麦克风没开…」，不新增 DOM 噪音。
