# UI-v4 Phase 8 · DESIGN

> 目标：把 v4 从「正确架构」提升到「高级 AI OS 产品体验」。
> 边界：只动表现层。不碰 Backend / Agent Runtime / Event / 页面数量 / 功能集合。

---

## 0. 设计命题

**用户打开这一屏的第一秒，应该发生什么？**

不是"看到一个仪表盘"，也不是"看到一个输入框"。
应该是——**意识到房间里有个人，他醒着，正在等你**。

由此得出 Phase 8 的三条设计律：

| 律 | 含义 | 落点 |
|---|---|---|
| **一 · 先有他，再有事** | 存在感优先于信息量 | Presence 占据视觉中心，Context 延后 420ms 出现 |
| **二 · 他说人话** | 状态是"他在说"，不是"系统在报" | 八态文案 + 上下文三句全部第一人称口语 |
| **三 · 安静比响亮贵** | 单色、大留白、微动 | 一个强调色 / 四级灰阶 / 动效 ≤ 520ms |

---

## 1. AI Core Identity 重构

### 1.1 形态：气 · 环 · 核

放弃"一团光晕 + 一个空环"，改为**三层同心结构**：

```
        ╭───────────────╮
        │   ○ aura      │  300px  外场：模糊呼吸光，表达"他的气"
        │  ╭─────────╮  │  122px  中环：发丝描边，规划/执行时有一道扫掠
        │  │    ●    │  │   44px  内核：带高光的球体，这就是"他"
        │  ╰─────────╯  │
        ╰───────────────╯
```

- **核（`.orb__core`）** —— 双层 radial-gradient：36%/30% 处一枚白色高光（球体感），
  中心为当前状态色。这是整屏唯一的"实体"。
- **环（`.orb__ring`）** —— 1px 发丝，仅在 PLANNING / EXECUTING 时浮出一道
  `conic-gradient` 扫掠光（用 `mask` 裁成环，`@supports` 兜底）。
- **气（`.orb__aura`）** —— 300px 模糊光晕，承担呼吸。

**定位方式**：三层用 `top:50% / left:50% + 负 margin` 居中，
把 `transform` 完整让给动画（避免 transform 冲突）。尺寸由 `--aura/--ring/--core`
三个变量驱动，响应式只需改变量 —— 彻底消灭 Phase 7 的魔法数字。

**红线遵守**：无面部、无五官、无表情、无卡通形象、无 Logo。只有光。

### 1.2 身份：三行，不是两行

```
        （光核）

    本地运行 · 你的 AI 副驾      ← kicker  10.5px mono  字距 .30em  最弱
           庄 周                 ← name    clamp(34–46px) 字距 .16em
      ● 在这里，随时开始          ← state   14px + 状态色脉冲点
```

- 名字**独占一行**，中文标题字距 `.16em` 并用 `text-indent` 抵消末字符边距保证真居中
  —— 这是中文排版做"贵"的关键一步。
- kicker 回答"他是谁"，name 回答"他叫什么"，state 回答"他此刻怎么样"。
  三行一次读完，身份闭环。

### 1.3 八态：颜色 + 节律 + 说法

**颜色唯一来源**：`avatar-state.js` 的 `META[state].color`。
`ai-core.js` 不硬编码任何色值，只做 `hex → rgba` 派生，注入四个 CSS 变量：

```
--core-color  实色      → 内核 / 脉冲点 / 主按钮
--core-soft   α .16     → 光晕内层 / 环境场 / focus ring
--core-glow   α .30     → 光晕核心 / 内核外辉
--core-line   α .42     → 扫掠光 / 强调下划线 / focus 描边
```

**节律与说法**（八态各不相同，状态因此"可感知"）：

| 状态 | 色值 | 呼吸周期 | 附加节律 | 小6说 |
|---|---|---|---|---|
| IDLE | `#5fb3c8` | 7.5s | — | 在这里，随时开始 |
| WAITING | `#f0b35e` | 4.2s | — | 等你确认一下 |
| THINKING | `#8b9bff` | 2.8s | 核同步加快 | 正在想这件事 |
| PLANNING | `#c08bff` | 3.6s | 环扫掠 6s | 正在把它拆开 |
| EXECUTING | `#56d364` | 2.0s | 环扫掠 2.4s + 环着色 | 正在做 |
| COMPLETED | `#56d3a0` | 6.5s | 转慢（"松一口气"） | 刚做完一件事 |
| ERROR | `#ff6b6b` | — | 1.5s 明暗起伏 | 卡住了，想请你看一眼 |
| OFFLINE | `#8a93a6` | 停 | 去饱和 + 光晕降至 .22 | 暂时离线 |

**换气**：状态文案切换时先淡出 150ms 再换字（`.is-swapping`），不做硬跳；
首帧例外——直接落定，避免开屏空白。

### 1.4 分工：Presence 不谈业务

| 元素 | 只说 | 绝不说 |
|---|---|---|
| `presence__state` | 我处于什么状态 | 目标名、ID、数量 |
| `presence__doing` | 此刻的临时反馈（"收到，我先理解一下"） | 常驻信息 |
| Context Layer | 我在理解什么 | 我是谁 |

这条分工直接消灭 Phase 7 的 `目标 #7` 泄漏与三处重复表达。

## 2. Context Layer：从数据槽位到三句人话

### 2.1 形式

删除 `DOING / KNOWN / WORLD` 全部标签。三段纯句子，居中，行高 1.9：

```
      我正在推进《总结当前项目状态》，快收尾了。      ← lead  15px  较亮
      我还记着你留意过《河南三支一扶笔试…》。         ← 14px  弱
      关于你的《决策》和《概念》，我大致有数了。       ← 14px  弱
```

关键实体用 `<em>` 包裹：不加粗不变色，只加一条 `--core-line` 的**下缘线**
（`box-shadow: inset 0 -1px 0`）—— 强调而不喧哗。

进场 stagger：0 / 90ms / 180ms，`line-rise` 上浮 7px。

### 2.2 语义规则（禁止数字外泄）

**① 正在** — `/api/goals`
- **按标题去重**，同名保留进展最大者（真实数据 7 条 → 1 条，直接治好 X-3）。
- 排序：进展降序 → 更新时间降序。取首条。
- 进度**译成措辞**，永不出现百分数：

  | progress | 说法 |
  |---|---|
  | ≤0 | 刚开了个头 |
  | <35 | 才起步 |
  | <67 | 推到一半了 |
  | <100 | 快收尾了 |
  | =100 | 基本落定了 |

- 若去重后仍 >1 条，补一句「手上另外还压着**两**件事」——中文数词，不是阿拉伯数字。
- 空：`此刻我没有在推进什么，你可以给我一个方向。`

**② 我记得** — `/api/memories`
- 修复解析（见 IMPLEMENTATION §1），按 `salience` 降序、`id` 降序取最重要的一条。
- **去噪**：剥掉 `Hotspot event:` / `用户提到热点：` / `Memory:` 等机器前缀。
- 按 `event_type` 换说法：热点→「你留意过」、决策→「你定下过」、目标→「你想做」。
- 空：`我还没记住什么，先跟我说说你在意的事。`

**③ 我理解** — `/api/knowledge`
- `domain/type` 经**中文映射表**（concepts→概念、decisions→决策、people→人和关系…）。
- 未映射且为纯 ASCII 的 slug **直接丢弃**（治好 X-2，英文永不进句子）。
- 按出现频次降序取前二：`关于你的《决策》和《概念》，我大致有数了。`
- 空：`你的世界我还了解得不多，慢慢来。`

### 2.3 刷新策略

`agent_state` 到达 → `V4Context.refresh()`，内部 **5s 限频**。
既让「正在」跟得上真实目标，又不让状态抖动打扰后端、不让文字闪烁。

## 3. 视觉语言

### 3.1 空间

```
--bg #08090c      近黑，不用纯黑（纯黑在 OLED 上失去纵深）
环境场 = 两层极淡径向渐变（上层随状态色变）+ 3.5% SVG 颗粒（overlay 混合）
```
颗粒用内联 `feTurbulence` data URI，零外部资源、零网络依赖。

### 3.2 留白

Presence 与 Context 是**唯一的流内元素**，作为一个整体在 flex 列中居中，
间距 `clamp(28px, 5vh, 52px)`，底部预留 132px 给 Intent Line。
—— 替换 Phase 7 的 grid 行 + 魔法 padding，布局从此可预测。

### 3.3 单色强调

全屏只有一个强调色（`--core-color`，由状态驱动），其余全部落在四级灰阶：

```
--text #edeff3 → --text-soft #c8ced8 → --text-dim #949ba7 → --text-faint #606774
```
分隔一律用发丝线 `rgba(255,255,255,.07)`，**不使用卡片、不使用阴影盒**。

### 3.4 微动效

| 动作 | 时长 | 曲线 |
|---|---|---|
| Presence 进场 | 720ms | `cubic-bezier(.16,1,.3,1)` |
| Intent 进场 | 640ms（延迟 180ms） | 同上 |
| Context 三行 | 520ms，stagger 90ms | 同上 |
| 状态换气 | 150ms | ease |
| 抽屉推入 | 520ms | ease-out |

全部 ≤ 520ms（进场 720ms 为一次性）；`prefers-reduced-motion` 下全量降为 1ms。

### 3.5 排版

| 角色 | 字号 | 字距 | 用途 |
|---|---|---|---|
| display | clamp(34–46px) / 500 | .16em | 小6 |
| kicker | 10.5px mono | .30em | 身份 / 分组标签 |
| lead | 15px | .02em | Context 首句 |
| body | 14px / 行高 1.9 | .02em | Context 其余 |
| meta | 11px mono | .04em | Overlay 次要信息 |

中文用**正字距**（.02–.30em）拉开呼吸，这是中文界面显"贵"的核心手法。

## 4. Intent Line

- **主按钮改 ghost**：默认透明、`--text-faint` 图标、不可点；有输入才点亮成实心
  （`.is-ready`）。彻底解决"ERROR 态红色主按钮"的语义冲突（按钮平时根本不存在）。
- **中文输入法保护**：`compositionstart/end` 打标，组词中拦截 Enter，绝不误提交。
- **随处即打**：焦点不在输入区时敲任意可见字符，自动聚焦意图线（不劫持快捷键）。
- **占位文案改成小6在说话**：`我在做，你可以先说下一件` / `我在等你确认` / `接下来做什么？`
- focus 时：描边转 `--core-line` + 4px `--core-soft` 光圈。

---

## 5. Ambient Navigation

从"汉字实心圆"改为 **5px 静默点**，悬停/激活时标签从右侧滑出（绝对定位，不挤布局）：

```
                      记忆 ●
                            ○
                            ○
```
激活点：填充状态色 + 4px soft 光圈。再次点击同一点收起抽屉。

## 6. Overlay

| 项 | 设计 |
|---|---|
| 标题 | 加人称 kicker：`我记住的 / 记忆`、`我在推进的 / 目标`、`关于我 / 关于` |
| 内容 | 行（`.row`），不是卡片；hover 仅 1.8% 提亮 |
| 记忆 | 复用 Context 的去噪函数，机器前缀不外露；来源译成「来自热点 / 来自对话」 |
| 目标 | 去重 + 进度措辞（复用 `_progressWord`），无百分数 |
| 知识 | 按中文域分组 |
| 世界 | 双圈布局：重要节点在外圈并标注，次要收内圈不标注；标签按角度左/右/中对齐避压叠 |
| 空态 | 改人话：`我还没记住什么。` / `跟我说说你在意的事，我会替你记着。` |
| 焦点 | 打开聚焦关闭键，关闭归还原焦点；Esc 返回并在页脚提示 |
