# UI-v4.1 Product Polish Sprint · Audit

> 身份：Senior Product Designer + Frontend Architect
> 范围：基于当前 `xiao6-ui/v4/` 的**产品级视觉与交互打磨**
> 红线：不重构架构 / 不新增功能 / 不改 Runtime / 不改后端 / 不新增事件 / 不恢复旧 UI / 不引入 Dashboard / 不做多页面

## 一、审计方法

逐文件读取 `v4/index.html`、`v4/ui-v4.css`、`v4/js/*.js`（共 7 个脚本），逐组件对照 v4.1 六维打磨目标，定位"正确的 AI OS 原型"与"高级 AI 产品界面"之间的差距。

## 二、逐组件审计结论

### 1. AI Core（光核 / Presence）
**现状**：`.orb` 三层（aura / ring / core），已有呼吸动画、planning/executing 环扫、pulse 点；八态颜色全部由 `avatar-state.js` 经 `--core-*` 注入；状态文案第一人称、无机器措辞。
**差距（P-present）**：
- 核心仍是"光球"质感，缺少"智能体在场"的层次——没有内禀光泽流动、没有环绕粒子，安静态偏"装饰"而非"活着"。
- 八态节律只改了 `animation-duration`，缺少**强度**差异（执行态应更亮更紧，思考态应有流转）。
- 环扫仅在 planning/executing 出现，其余态环是静止发丝线，整体"生命周期感"不足。

### 2. Context Layer（正在 / 我记得 / 我理解）
**现状**：三句小6第一人称表达，无数字卡片、无 Dashboard；目标去重取进展最大者；记忆剥机器前缀；知识域英文 slug 已映射中文。真实数据已激活（记忆 34 条）。
**差距**：逻辑已达标，仅余微排版（三句行距偏紧、lead 强调可更克制）与极端空态措辞。属可打磨项，非缺陷。

### 3. Intent Line（唯一入口）
**现状**：底部胶囊、ghost 发送键、聚焦描边、中文组词拦截、任意键聚焦、状态联动占位文案。
**差距**：聚焦态描边偏"输入框感"；发送就绪无入场动效；提交后仅核心区文字反馈，输入框本身缺少"已送出"的微交互。

### 4. Overlay（Memory / Knowledge / Goal / World / Settings）
**现状**：右侧抽屉、行式、第一人称 kicker、空态人话、焦点管理、⌘1–5 唤出。
**差距（P-overlay）**：内容开头仅一个标题（如"记忆"）+ kicker（"我记住的"），下方直接是行——读起来仍像"一个带标题的列表/菜单"，未充分表达"这是小6展开给你看的一面能力"。缺一句小6口吻的引导语。

### 5. 顶部区域（Topbar）
**现状**：56px 固定栏，左侧"小6 AI OS · Presence Space"，右侧两个描边状态徽章（本地模式 / 在线）+ 时钟。
**差距（P-top，最重）**：**最像"软件标题栏"的源头**——双徽章 + 连接状态条营造出"应用程序 chrome"观感，直接违背"这是我的 AI"而非"这是一个软件界面"。品牌词"AI OS · Presence Space"也偏工程自述。

### 6. World Understanding
**现状**：默认隐藏，仅 ⌘4 / 世界点唤出；SVG 2D 关系图，重要节点外圈、标签防压叠；数据取自 `/api/memories/graph`。
**差距**：符合"保持隐藏、仅入口"要求。仅标签字号偏小（8.5px）、可读性可微提。属可选打磨。

## 三、红线合规基线（进入打磨前已确认）

| 红线 | 当前状态 |
|---|---|
| 不恢复旧导航 / Galaxy 首页 | ✅ 无 `app.js`/`main-orb.js`/`galaxy`/`three` 引用 |
| 不引入 Dashboard / 卡片墙 | ✅ Context 为三句语义，Overlay 为行式 |
| 不做多页面 | ✅ 单空间 + Overlay |
| 不改后端 / Runtime / 事件 | ✅ 仅消费既有 REST + SSE `agent_state` |
| 不新增事件 | ✅ 无新事件契约 |

## 四、打磨优先级（六维 → 落地项）

| 维度 | 落地项 | 优先级 |
|---|---|---|
| 顶部区域 | 去 chrome：活体存在点 + 耳语隐私 + 极淡时钟；移除双徽章与"AI OS · Presence Space"自述 | P0 |
| AI Core | 内禀光泽流转（shimmer）+ 环绕粒子（satellite，活跃态显形）+ 八态强度差异 | P0 |
| Overlay | 每类加一句小6引导语（能力展开，非菜单）+ 行入场微动效 | P1 |
| Intent | 聚焦态柔光 + 发送就绪入场 + 提交微交互 | P1 |
| Context | 三句行距放宽、极端空态措辞微调 | P2 |
| World | 标签字号/对比微提 | P2 |

全部为**表现层 CSS / 文案改动**，零结构、零事件、零后端。
