## 2. 适配层：`data-adapter.js`

后端接口返回形态不一致（数组 vs 对象），`asList(v, key)` 统一收敛：

```js
function asList(v, key) {
  if (Array.isArray(v)) return v;
  if (v && Array.isArray(v[key])) return v[key];
  return [];
}
```

**关键修复（X-1）：** `/api/memories` 返回的是**裸数组**，旧代码按 `{memories:[]}` 解析导致记忆恒为空。修复后 memories = 34 条。

## 4. Context Layer 三句映射

### ① 正在 → Goal

函数：`pickGoal(goals)`

- 按标题去重，保留进展最大者。
- 排序：progress 降序 → updated 降序。
- 取 top 1。
- `progressWord(p)` 把数字译为自然措辞。

**关键修复（X-3）：** 旧代码 `goals[0]` 取到 progress:0 的重复标题；修复后取到真实推进目标
（"总结当前项目状态", 83%）。去重后 7 → 1。

### ② 我记得 → Memory

函数：`pickMemory(memories)`

- 按 `salience` 取最重要一条。
- `cleanMemory()` 剥除机器前缀：
  - `Hotspot event:`
  - `Memory:`
  - `用户提到热点:`
  - `用户:`
- `memoryPhrase()` 按 `event_type` 换说法：
  - `hotspot` → "我还记着你留意过…"
  - `decision` → "我还记着你定下过…"
  - `goal` → "我还记着你想做…"
  - 其他 → "我还记着…"

### ③ 我理解 → Knowledge

函数：`domainLabels(docs)`

- 英文 slug → 中文映射：
  - `concept/concepts` → 概念
  - `decision/decisions` → 决策
  - `people/person` → 人和关系
  - `project/projects` → 项目
  - `architecture/arch` → 架构
  - `note/notes` → 笔记
  - `doc/docs/document` → 文档
  - `system/systems` → 系统
  - 其他未映射的纯 ASCII slug 直接丢弃。
- 按出现次数排序。

**关键修复（X-2）：** 旧代码展示 `concept` 等英文 slug；修复后只输出中文域。

## 7. 数据纪律

- v4 JS 中没有 `POST/PUT/DELETE` 到 goals/memories/knowledge。
- 唯一写操作是 `ZZIntentGateway.dispatch(text)`，复用旧链路。
- 所有 GET 失败均静默降级，不弹错误面板。
