# 小6 AI OS · v4 设计说明

> 不是聊天软件。不是 Dashboard。不是太阳系首页。  
> 是一个**个人 AI 操作系统**的 first real interface。

---

## 1. 产品定位

**小6 = 用户打开电脑后，一个一直存在的 AI 副驾。**

核心体验链：

```
打开小6
  ↓
看到小6正在这里
  ↓
知道它现在的状态
  ↓
知道它记住什么、理解什么
  ↓
告诉它我要什么
  ↓
它自动执行
```

一句话：**一个空间，一个 AI，一个入口。**

---

## 2. 彻底退出首屏的旧元素

| 旧元素 | 处理方式 | 原因 |
|---|---|---|
| 左侧导航栏 | 删除 | AI OS 不是传统软件菜单 |
| 太阳系 Galaxy | 退出首页，变为 World Understanding Overlay | 没有任务价值，视觉抢注意力 |
| Dashboard 卡片（目标/记忆/知识数量） | 禁止 | AI 不应该展示数据库 |
| 聊天窗口 | 禁止 | 不是对话工具，是执行副驾 |
| 多页面 / 路由切换 | 禁止 | 单空间，零页面跳转 |

---

## 3. 新首页空间结构

整个界面只有一个 `<main class="space">`：

```
┌────────────────────────────────────────────┐
│  小6 AI OS · Presence Space        在线   │  ← topbar
├────────────────────────────────────────────┤
│                                            │
│                    ○                       │  ← AI Core（光核）
│                  小6                      │
│              在这里，随时开始               │
│                                            │

└────────────────────────────────────────────┘
        · · · · ·  （右侧 ambient 快捷点）
```

## 4. AI Core — 视觉与状态中心

### 位置与形态
- 屏幕几何中心。
- 不是头像，不是机器人，不是按钮。
- 是一个**光核（Presence Orb）**：气 / 环 / 核三层。

### 状态驱动
八态来自 `avatar-state.js` 的单一权威：

```
IDLE      → 在这里，随时开始
WAITING   → 等你确认一下
THINKING  → 正在想这件事
PLANNING  → 正在把它拆开
EXECUTING → 正在做
COMPLETED → 刚做完一件事
ERROR     → 卡住了，想请你看一眼
OFFLINE   → 暂时离线
```

颜色、动画节律、脉冲速度全部随状态变化：
- `IDLE` 慢呼吸；`EXECUTING` 快环扫；`ERROR` 急促告警；`OFFLINE` 暗淡静止。

### 文案纪律
- 第一人称（"我在…" / "等你…"）。
- 不出现「中」「状态」「系统」「仪表」等机器措辞。

---

## 5. Context Layer — 三句语义

把「正在 / 我记得 / 我理解」表达成小6自己的三句话，**不是数据槽位**。

| 区域 | 数据来源 | 表达示例 |
|---|---|---|
| 正在 | `/api/goals` | 我正在推进**总结当前项目状态**，快收尾了。 |
| 我记得 | `/api/memories` | 我还记着你留意过**河南三支一扶笔试存在组织作弊犯罪**。 |
| 我理解 | `/api/knowledge` | 关于你的**决策**和**概念**，我大致有数了。 |

纪律：
- 禁止阿拉伯数字、百分号、英文 slug。
- 进度译为自然措辞：刚开了个头 / 才起步 / 推到一半了 / 快收尾了 / 基本落定了。
- 英文知识域映射为中文：concept→概念、decisions→决策、people→人和关系、projects→项目。

---

## 6. Intent Line — 唯一输入入口

底部中心一条线，替代：聊天页、命令面板、功能菜单。

```
──────────────────────────────────────
  告诉小6你想完成什么…              ↑
──────────────────────────────────────
```

- 默认 ghost，有内容才点亮发送键。
- 任意位置直接敲字即可落入意图线。
- 中文输入法组词中拦截 Enter 误提交。
- 走既有链路：`ZZIntentGateway.dispatch → POST /api/agent/intent`。

---

## 7. World Understanding — 2D 关系图

替代 Galaxy 太阳系：
- 技术：**SVG 2D**，禁止 Three.js / 星球 / 轨道。
- 数据：`/api/memories/graph` + `galaxy-state.js`。
- 入口：快捷键 `⌘4` / `Ctrl+4`，或右侧 ambient 点。
- 呈现：重要节点外圈带标签，次要节点内圈无标签，边用细线连接。

---

## 8. Overlay — 空间内聚焦

不离开首页的侧向浮层：

| 快捷键 | 内容 |
|---|---|
| `⌘1` | 记忆 |
| `⌘2` | 知识 |
| `⌘3` | 目标 |
| `⌘4` | 世界理解 |
| `⌘5` | 关于 |
| `Esc` | 关闭 |

纪律：
- 行式列表，不是卡片。
- 标题用第一人称 kicker（"我记住的" / "我在推进的"）。
- 不展示统计数字。

---

## 9. 视觉规范

### 颜色
- 背景：`#05070c`（唯一深色）。
- 文本：四级灰阶 `#edeff3` → `#606774`。
- 强调：唯一来源 `avatar-state.js` 八态色，通过 `--core-*` 变量注入。

### 风格关键词
高级、安静、未来、可信。

### 禁止
- 玻璃卡片墙
- 边框堆叠
- 渐变背景
- 星空装饰
- 数据墙 / 仪表盘
- 左侧菜单
- 多页面
- 彩色主题切换

### 动效
- 慢入快出，全部 ≤ 720ms。
- 呼吸、换气、微抬升，无炫目特效。

---

## 10. 与旧 UI 的关系

- `xiao6-ui/v4/` 是**全新目录**。
- 旧代码（`app.js` / `main-orb.js` / Galaxy 等）**不被加载**。
- 仅复用能力单例：`sse-manager.js`、`zz-events.js`、`avatar-state.js`、`intent-gateway.js`。
