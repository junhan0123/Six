# 小6 AI OS · v4 架构说明

v4 是**表现层重构**。后端、Agent Runtime、EventBus、AppState、Memory、Goal、Knowledge 均未被修改。

---

## 1. 目录结构

```
xiao6-ui/v4/
├── index.html              # 单页空间结构
├── ui-v4.css               # 视觉语言 + 状态节律
└── js/
    ├── data-adapter.js     # REST 快照 + SSE 订阅
    ├── ai-core.js          # Presence（光核 / 状态 / 文案）
    ├── context-layer.js    # 三句语义生成
    ├── intent-line.js      # 唯一输入入口
    ├── overlay.js          # 空间内 Overlay
    ├── world-understanding.js # SVG 2D 关系图
    └── boot.js             # 启动编排 + topbar 时钟/连接态
```

复用的旧能力单例（不加载旧 UI）：

```
xiao6-ui/
├── sse-manager.js
├── zz-events.js
├── avatar-state.js        # 八态颜色 + 派生逻辑（唯一权威）
└── intent-gateway.js      # 意图 POST 网关
```

---

## 2. 组件边界

| 组件 | 职责 | 不做什么 |
|---|---|---|
| `data-adapter.js` | 只读消费 `/api/*`；订阅 SSE `agent_state` | 不写后端；不新增事件 |
| `ai-core.js` | 把 runtime 状态映射为 Presence 视觉 | 不持有业务状态；不定义颜色 |
| `context-layer.js` | 把 goals/memories/knowledge 译为三句话 | 不做统计面板/数字卡片 |
| `intent-line.js` | 收集用户意图并提交 | 不实现聊天 Runtime |
| `overlay.js` | 在单空间内展示记忆/知识/目标/世界/关于 | 不做路由/新页面 |
| `world-understanding.js` | SVG 2D 关系图 | 不加载 Three.js |
| `boot.js` | 启动顺序 + topbar 状态 | 不初始化旧 UI |

## 3. 启动与数据流

```
页面加载
  ↓
加载复用单例（sse-manager / zz-events / avatar-state / intent-gateway）
  ↓
加载 v4 JS 模块
  ↓
boot()
  ├── ensureSSE()              # 只启动既有 SSE
  ├── fetchSnapshot()          # GET /api/goals /api/memories /api/knowledge /api/agent/state
  ├── applyState(agentState)   # AI Core 定色 + 文案
  ├── setPlaceholder(state)    # Intent Line 占位文案
  ├── render(snap)             # 420ms 后 Context 出现
  └── setSnapshot(snap)        # Overlay 预填数据
  ↓
onAgentState(SSE)              # 实时更新 Presence + Context 限频刷新
```

---

## 4. 状态权威

**Avatar 八态的唯一来源是 `avatar-state.js META`。**

`ai-core.js` 不硬编码任何颜色。它只把 `AvatarState.META[state].color` 转换为 4 个 CSS 变量：

```css
--core-color  /* 1.0 */
--core-soft   /* 0.16 */
--core-glow   /* 0.30 */
--core-line   /* 0.42 */
```

整个 v4 的所有强调色都由这 4 个变量驱动。

---

## 5. 事件契约

v4 只使用一个 SSE 事件：

```js
{
  "xiao6_event": "agent_state",
  "state": "EXECUTING"   // 或 idle/planning/reflecting/disabled/...
}
```

**没有新增事件名。没有新增后端接口。没有修改 EventBus。**

---

## 6. 意图链路

用户输入 → `intent-line.js` → `ZZIntentGateway.dispatch(text)` → `POST /api/agent/intent`。

与旧 UI 的 `command-dock.sendText()` 走同一后端链路，零重新实现。

---

## 7. 响应式与安全

- 断网 / runtime 关闭：AI Core 进入 `OFFLINE`，Context 静默，不弹错误面板。
- 中文输入法：`compositionstart/end` 拦截 Enter 误提交。
- 无障碍：`aria-label`、`aria-live`、`aria-modal`、`:focus-visible`。
- `prefers-reduced-motion`：关闭所有动画。
