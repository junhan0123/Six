# 01 · UI-v3 信息架构（INFORMATION ARCHITECTURE）

> **阶段**：UI-v3 Clean Reconstruction · Phase 1（Design Only）
> **依赖**：`00_UI_V3_AUDIT_FINAL.md`
> **目标**：定义 v3 首页的全新结构——不是"页面"，是小6的「存在界面」（Presence Surface）。

---

## 1. 第一性原理

旧首页的隐含模型是：**用户来用功能**（导航到工作台 / 指令 / 星图 / 设置）。

v3 的模型反转：**用户来与小6相处**。首页回答四个问题——
1. 小6是谁？（身份）
2. 小6现在什么状态？（在场）
3. 小6在做什么 / 知道什么？（语境）
4. 我怎么跟它说话？（意图）

因此首页不是"功能入口集合"，而是**小6此时的存在状态**。一切信息环绕一个中心（AI Core）辐射，而非分栏陈列。

---

## 2. 新首页 = 单一「存在界面」（Presence Surface）

```
┌─────────────────────────────────────────────────────────┐
│                                                           │
│            ◉  AI Core（小6本人 · 唯一视觉中心）            │
│        身份 · 状态 · 正在处理 · 下一步建议                  │
│                                                           │
│   ┌──────────────┐            ┌──────────────┐            │
│   │ Context Layer │            │ Context Layer │           │
│   │  正在处理      │            │  记住了 / 知道  │           │
│   └──────────────┘            └──────────────┘            │
│                                                           │
│   ┌─────────────────────────────────────────────┐        │
│   │  Intent Line  ·  全屏唯一输入（向小6说话）    │        │
│   └─────────────────────────────────────────────┘        │
│                                                           │
└─────────────────────────────────────────────────────────┘

  Overlay Layer（⌘ 唤起的覆盖层，不常驻，不在首屏）：
    ⌘K 指令面板 · ⌘4 理解网络 · ⌘, 设置 · ⌘ 上下文抽屉
```

**关键差异 vs 旧结构**：
- 旧：三栏（`os-nav` / `os-core+os-side` / `os-bottom`）+ 11 个浮层容器 + 三个独立心智。
- 新：一个中心 + 环绕语境 + 一条意图 + 按需覆盖层。**没有侧栏、没有底部面板、没有 HUD、没有状态条**。

---

## 3. 四层架构

### Layer 1 · Presence Layer（在场层）—— AI Core
- **位置**：视口几何中心（非角落、非边缘）。
- **内容**：小6化身（光核）+ 身份（"小6"）+ 当前状态（来自 `avatar-state` 8 态）+ 正在处理（一句）+ 下一步建议（一句）。
- **角色**：唯一视觉重心。所有其他层的信息密度都低于它，视觉权重最高。
- **详见**：`02_AI_CORE_DESIGN.md`。

### Layer 2 · Context Layer（语境层）—— 环绕 AI Core
- **位置**：AI Core 两侧 / 下方，低对比、随滚动/状态淡入。
- **内容**（全部来自既有 API，非面板、非卡片）：
  - **正在处理**：当前 Goal 的执行进度流（替代旧 `os-timeline` 面板）→ 取 `/api/goals?status=active`。
  - **记住了**：最近一条记忆微提示（淡入）→ 取 `/api/memories?limit=1`。
  - **知道**：知识库语义化摘要一行（"已掌握你的项目架构与设计"）→ 取 `/api/knowledge`。
- **原则**：语境信息是"小6知道的事"，融入氛围，**不是三个并排面板**。出现即淡入，不争夺中心。

### Layer 3 · Intent Layer（意图层）—— Intent Line
- **位置**：底部居中、宽度受限（约 720px max，参考 Raycast 命令框），悬浮于 Context 之下。
- **内容**：单个输入框 + 发送（复用 `#osDock` + `sendText`）。占位符随 `agent_state` 事件切换（IDLE/THINKING/EXECUTING/ERROR）。
- **角色**：全屏**唯一**输入入口。用户说一句话，小6理解 → 可能转为 Goal → 在 Context Layer「正在处理」流中可见。
- **详见**：`03_INTENT_LINE_DESIGN.md`。

### Layer 4 · Overlay Layer（覆盖层）—— 按需唤起
- **不常驻**、不在首屏。⌘ 快捷键或 Ambient 微点唤起，覆盖于 Presence Surface 之上，关闭即回存在界面。
- **成员**：
  - `⌘K` 指令面板（复用既有 command palette 入口）
  - `⌘4` 理解网络（Galaxy 降级产物，见 `04`）
  - `⌘,` 设置（含主题选择器，从 HUD 迁入）
  - `⌘` 上下文抽屉（能力矩阵 + 洞察，从 `os-side` 迁入，已有 `osContextToggle`）
- **原则**：覆盖层是"深入某件事"，不是"离开首页去另一个软件"。关闭即回小6面前。

---

## 4. 导航模型（红线：不允许左侧导航）

v3 **没有 `.os-nav`**。导航通过三种机制，全部不破坏"单一空间"：

1. **意图即导航**（主）：用户用自然语言指挥小6，小6自己编排（Goal System）。大多数"去哪"由说一句话解决。
2. **键盘快捷键**（高效）：`⌘K` 指令 / `⌘4` 理解网络 / `⌘,` 设置 / `⌘` 上下文抽屉。参考 Raycast 的效率范式。
3. **Ambient 微点**（探索）：AI Core 周围 2–3 个极轻量指示点（如"查看小6如何理解你的世界"），点击唤起对应 Overlay。**不形成左侧导航栏**。

> 旧 `os-nav` 的五个能力（工作台/指令/星图/语音/设置）**全部保留**，只是入口从"左侧常驻栏"变为"快捷键 + Overlay + 语音按钮（在 Intent Line 内）"。功能不删，仅改变首屏呈现。

---

## 5. 首次 30 秒认知流（验收基准）

| 时间 | 用户应建立的认知 | 由哪层承载 |
|---|---|---|
| **5 秒** | "这是小6，一个本地 AI 副驾，它现在在线" | Presence Layer（身份 + 状态色） |
| **15 秒** | "它在做 X（当前目标），它记得 Y，它懂我的项目" | Context Layer（正在处理 / 记住了 / 知道） |
| **30 秒** | "我该在底下这行跟它说话" | Intent Line（唯一输入框 + 占位符提示） |
| 之后 | "需要深入时按 ⌘ 唤起对应视图" | Overlay Layer |

**无认知负担**：不需要理解"我在哪个页面"、不需要找导航、不需要辨别三个软件。

---

## 6. 旧结构 → 新结构 对照

| 旧 DOM | 旧角色 | v3 去向 |
|---|---|---|
| `.os-nav` | 左侧导航 | 隐藏；能力转快捷键/Overlay |
| `.os-hud` | HUD | 隐藏；状态入 AI Core，主题入设置 Overlay |
| `.os-core` | 英雄区（角落） | 升为**中心** AI Core（Presence Layer） |
| `.os-side` 双面板 | Dashboard 侧栏 | 隐藏；转 ⌘ 上下文抽屉 Overlay |
| `.os-bottom .os-timeline` | 底部面板 | 隐藏；转 Context Layer「正在处理」流 |
| `.os-bottom .os-dock` | 指令坞 | 重定位为底部 Intent Line |
| `.os-readout` | 状态条 | 隐藏；信息并入 Context Layer |
| `#solarCanvas` | 星系首页 | 降级；转 ⌘4 理解网络 Overlay |
| `.os-hero-actions` 3 按钮 | 多入口 | 删除（隐藏）；唯一入口 = Intent Line |

---

## 7. 空间心智总结

- **不是页面，是表面**：用户不"切换页面"，只在小6的存在界面上与之相处。
- **一个中心**：AI Core 永远在视觉重心，其他信息环绕、退后。
- **一个入口**：Intent Line 是全屏唯一输入框。
- **深入靠覆盖层**：需要时 ⌘ 唤起，用完即回，空间不碎。
