# 05 · 视觉设计语言（VISUAL LANGUAGE）

> **阶段**：UI-v3 Clean Reconstruction · Phase 1（Design Only）
> **依赖**：`00`（废弃五代叠加 + 9 色选择器 + 玻璃卡片）/ `02`（8 态色板）
> **目标**：定义 v3 单一视觉语言——简洁、高级、科技感，像真正的 AI OS。
> **参考方向**：Apple 产品极简 · Linear 信息密度 · Raycast 效率 · Claude Desktop 自然交互。

---

## 1. 设计原则（四条）

1. **中心辐射，而非分栏**：信息环绕 AI Core，而非堆在侧栏/底部面板。负空间是设计元素。
2. **单一状态色，而非主题墙**：全站只有"当前 AI 状态色"一个强调色（来自 `avatar-state`），不提供 9 色主题切换（旧 HUD 装饰）。
3. **语义靠明度，而非颜色堆砌**：层级用同色相的明度/透明度区分，避免多色噪点。
4. **动效有目的，≤400ms**：每次动效都表达"状态变化"或"空间关系"，禁止装饰性炫技。

---

## 2. 色彩（Color）

### 2.1 基础（深色优先）
| Token | 值（建议） | 用途 |
|---|---|---|
| `--bg` | `#0a0c10`（近黑，带蓝调） | 全局背景 |
| `--bg-raise` | `#11141a` | 浮层/覆盖层背景 |
| `--text-bright` | `#e8ecf2` | 主文本（身份/标题） |
| `--text-base` | `#aab2c0` | 正文 |
| `--text-dim` | `#6b7484` | 次要/占位符 |
| `--line` | `rgba(255,255,255,0.08)` | 细线分隔（hairline） |
| `--line-strong` | `rgba(255,255,255,0.14)` | 交互边界 |

> 深色为默认；Light 变体本期**非必须**（见 `06` 开放决策）。若做，仅反转明度，结构不变。

### 2.2 唯一强调色 = AI 状态色（复用 avatar-state）
| Token | 来源 | 用途 |
|---|---|---|
| `--core-color` | `avatar-state.color(state)` | AI Core 光核、Intent Line 输入线、状态点、下一步建议高亮 |

- **全站只此一个强调色**，随小6状态流动（IDLE 青 → THINKING 蓝 → EXECUTING 绿 → ERROR 红）。
- 不使用 9 色主题（废弃）；不使用多色标签墙。

### 2.3 语义辅助色（极少，仅状态/类型）
- Goal/Agent/Memory/Knowledge 节点（理解网络）可用**同明度不同色相的克制区分**，但整体仍服从"单一强调 + 明度层级"原则，避免回到 Galaxy 的彩色噪点。

---

## 3. 字体（Typography）

| 角色 | 字体 | 字号/字重 | 说明 |
|---|---|---|---|
| 身份标题 | 系统无衬线（PingFang / SF / Segoe） | 28–34px / 600 | "小6"——低对比、克制 |
| 正文 | 同上 | 14–15px / 400 | Context Layer 文案 |
| 数据/状态 | 等宽（SF Mono / JetBrains Mono） | 13px | 进度、时间戳、计数（Linear 密度感） |
| 占位符 | 系统无衬线 | 16–17px | Intent Line 引导文案 |

- **不用花哨字体**；系统字体保证跨平台一致与"高级感"。
- 等宽仅用于数据/状态，强化"机器在做事"的科技感（Raycast 范式）。
- 字号层级少而清晰，拒绝旧 HUD 的多种字号混排。

---

## 4. 空间（Space）

- **中心辐射布局**：AI Core 视口几何中心；Context 环绕其下/侧；Intent Line 底部居中悬浮。无 Grid 分栏。
- **负空间即结构**：区块之间用大留白 + 单根 hairline 分隔，不用卡片边框/阴影。
- **尺度令牌**（沿用 `ui2.css` 命名，避免重新发明）：
  - `--space-2`(8) `--space-3`(12) `--space-4`(16) `--space-6`(24) `--space-8`(32)
  - 圆角：`--r-2`(8) `--r-3`(12) `--r-4`(16)（克制，不用大圆角玻璃）
- **响应式**：废除旧 `scale()` 伪响应式骗局（v2 审计已判）；用真实 `clamp()` / 媒体查询，AI Core 居中与 Intent Line 宽度随视口自适应。

---

## 5. 动效（Motion）

| 动效 | 时长 | 缓动 | 目的 |
|---|---|---|---|
| 状态色过渡 | 320ms | `ease-soft`（沿用 ui2 令牌） | 表达小6状态变化 |
| AI Core 呼吸 | 4000ms 循环 | linear/soft | 表达"活着"，幅度极小 |
| 浮层进出 | 240ms | `ease-soft` | 覆盖层唤起/关闭的空间关系 |
| Context 淡入 | 280ms | `ease-soft` | 信息出现时不突兀 |
| 焦点微放 | 200ms | `ease-soft` | hover/点击 AI Core 的可交互暗示 |

- **统一缓动**：沿用 `ui2.css` 的 `--ease-soft` 等令牌，不新造。
- **禁止**：旋转、翻转、粒子、扫描线、弹跳、3D 透视等炫技动画。
- **尊重 prefers-reduced-motion**：用户开启时，呼吸/淡入降级为静态。

---

## 6. 组件语言（Components）

- **无玻璃卡片**：废弃 `backdrop-filter` + 阴影的 `.os-panel`。区块用"留白 + 单 hairline"界定。
- **无重边框**：边界只用 `--line`（8% 白）细线；交互态用 `--line-strong` 或 `--core-color` 细线。
- **无图标墙**：Ambient 微点 ≤3 个，极轻量；不堆功能图标。
- **Intent Line**：一条悬浮输入线，非卡片、非面板（见 `03`）。
- **AI Core**：光核 + 文字，无外框容器。

---

## 7. 单一样式表策略（关键：替换而非叠加）

- v3 首页**只加载一个样式表** `ui-v3.css`（或等价），**不链接**五代叠加（ui4b/c/d、ui5d）与 P0-B/P1 补丁（ui-v2-*）。
- `ui-v3.css` 可**复用 `ui2.css` 的 token 命名与值**（颜色/空间/缓动/z-index 阶梯），但**不继承其 os-shell/os-nav/os-hud/os-panel 布局规则**。
- 旧布局类名（`.os-shell`/`.os-nav`/`.os-hud`/`.os-side`/`.os-panel`）在 v3 首页**不再使用**——它们自然失效（DOM 隐藏或不在 v3 文档中出现）。
- **这是根治"五代叠加"病灶的结构解法**：一次替换，不再累积化妆层。

---

## 8. 验收（视觉维度）

- [ ] 深色优先，全站仅一个强调色（AI 状态色），无 9 色主题。
- [ ] 无玻璃卡片、无重边框、无图标墙；区块靠留白 + hairline。
- [ ] 字体系统无衬线 + 等宽（数据），字号层级清晰。
- [ ] 动效 ≤400ms、有目的、统一缓动，无炫技。
- [ ] 首页只加载单一 v3 样式表，无五代叠加。
- [ ] 真实浏览器中呈现"简洁 / 高级 / 科技感 / 像 AI OS"。
