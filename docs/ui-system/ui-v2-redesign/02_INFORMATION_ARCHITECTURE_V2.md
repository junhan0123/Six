## 1. 导航范式的根本转换

### 现状（必须废除）

```
Home | Workspace | Command | Galaxy | Assistant | Settings
```

**六项，且每一项都是"页面"。** 三处硬伤：

1. 超出 5 项红线；
2. `Workspace` 与 `Assistant` 指向同一个 `.app`，仅差一个 `navVoice` 布尔 —— 两个入口一个目的地；
3. 以**软件模块**命名，用户被迫先回答"我该去哪个页面"，再回答"我要干什么"。

### v2 范式

> **导航的不是页面，是 AI 的注意力。**

用户不在"切换页面"，而在告诉小6：**现在关注这一面**。

因此一级导航必须回答的问题不是 "Where am I?"，而是 **"What is my AI attending to?"**

## 2. 一级导航：Focus Spine（焦点脊柱）

**5 个焦点，不多不少。**

| # | 焦点 | 英文 | 一句话 | 快捷键 | 频率 |
|---|---|---|---|---|---|
| 1 | **此刻** | NOW | AI 在场 + 今天要紧的事 | `⌘1` | 极高（默认） |
| 2 | **在做** | DOING | 目标、任务、正在执行的一切 | `⌘2` | 高 |
| 3 | **记得** | KNOWN | 记忆与知识，小6的积累 | `⌘3` | 中 |
| 4 | **在看** | SENSING | 世界态势与主动洞察 | `⌘4` | 中 |
| 5 | **是谁** | SELF | 人格、能力、授权、设置 | `⌘5` | 低 |

### 为什么是这五个

它们不是功能分类，是**一个智能体的认知循环**：

```
        在看 SENSING  ──感知世界──┐
             ↑                    ↓
        是谁 SELF              记得 KNOWN
        （自我）                （积累）
             ↑                    ↓
        此刻 NOW  ←──呈现──   在做 DOING
                              （行动）
```

用户切换焦点 = 把手电筒照向智能体心智的不同侧面。**五个焦点覆盖一个 Agent 的全部存在方式，没有第六种。**

### 命名纪律

- 全部用**中文动词/状态**，不用名词化的模块名
- 每个词 2 个字，视觉等宽，脊柱整齐
- 英文代号仅用于代码与文档，UI 不展示

**被否决的候选命名：**

| 候选 | 否决理由 |
|---|---|
| 首页 / 工作台 / 助手 | 软件菜单词汇，明令禁止 |
| 目标 / 记忆 / 知识 | 名词=数据仓库心智，弱化了 AI 的主体性 |
| Dashboard / Inbox | 管理后台气质 |
| 对话 / Chat | 对话是常驻层，不是焦点（见 §4） |

## 3. 不进入导航的三样东西

这是本 IA 最重要的三个减法。

### 3.1 对话 —— 降级为常驻层

**对话不是焦点，是贯穿全部焦点的输入通道。**

```
┌─────────────────────────────────────────┐
│                                         │
│         [ 任意焦点的内容区 ]              │
│                                         │
├─────────────────────────────────────────┤
│  ▸ 对小6说点什么…                  ⌘K  │  ← Intent Line 永远在
└─────────────────────────────────────────┘
```

- 在**任何**焦点下都可见、可聚焦、可发送
- AI 的回应在**当前焦点内**就地展开，不切换空间
- 全局 `⌘Space` 唤起悬浮意图行（即使小6不在前台）
- 历史对话是 KNOWN 焦点下的一个视图，不是独立软件

> 这一条直接兑现了红线："**Chat 不是独立软件**"。

### 3.2 指令中心 —— 合并进意图行

现状 `command-palette.js`（357 行）与 Intent Line 是**同一件事的两种壳**：都接收自然语言、都触发能力。

v2：**只保留一个输入口。**

```
在意图行输入 "/" 或 ⌘K  →  同一个输入框切换为命令模式
```

不新建面板，不新建入口。少一个导航项，少一套心智。

### 3.3 Galaxy —— 移出一级导航

理由见 `05_GALAXY_ROLE_REDESIGN.md`。结论：天文形态移除，关系图谱作为 KNOWN 焦点下的**视图模式**存在。

> 兑现红线："**Galaxy 不是主页**"——它连一级导航都不是。

## 4. 完整信息架构

### 焦点 1 · 此刻 NOW（默认，⌘1）

**定位**：AI 的在场证明 + 今日唯一要紧的事。
**频率**：★★★★★（打开即在此）

| 二级 | 内容 | 数据源 | 现状 |
|---|---|---|---|
| Presence Core | AI 状态可视化（呼吸核心） | `AvatarState` / `body[data-presence]` | ✅ 复用 |
| 主动开口 | AI 对今天的判断（1–2 句） | `proactive.py` + `learnings` | ⚠️ 引擎在，UI 缺 |
| 今日态势 | 在做 N / 记得 N / 在看 N | goals+tasks / memories / pending_proactive | 🆕 新建 |
| 就地执行流 | 当前任务的实时步骤 | `ExecutionChannel` | ✅ 复用 |

**设计约束**：此焦点**最多 4 个视觉元素**。这是全系统信息密度最低的地方，密度即噪音。

---

### 焦点 2 · 在做 DOING（⌘2）

**定位**：目标与任务的执行空间。**v2 最大增量。**
**频率**：★★★★☆

| 二级 | 内容 | 数据源 | 现状 |
|---|---|---|---|
| 目标流 | 活跃目标 + 进度（子任务聚合） | `goals.py` 17 函数 | 🆕 **后端完整，前端为零** |
| 任务流 | open/doing/done 任务 | `tasks` 表（14 行全 open） | 🆕 无闭环 UI |
| 执行时间线 | 步骤级实时执行 | `ExecutionChannel` / `agent_runtime.py` | ✅ 复用 |
| 授权待办 | 需确认的高风险动作 | `policy_engine` / `permission_guard` | ⚠️ 有后端无 UI |
| 计划 | 定时与循环任务 | `scheduler.py` | ⚠️ 有后端无 UI |

**必须补的后端**：`server.py` **从不 import goals** —— 需新增 `/api/goals` REST 层（GET/POST/PATCH/DELETE + plan）。这是 v2 唯一必要的后端改动，且不改任何业务逻辑，只补 HTTP 暴露。

**交互纪律**：目标**不通过表单创建**。用户在意图行说一句话 → AI 解析 → 卡片确认 → 落库。`goal_decision_engine.py` 已具备此能力。

---

### 焦点 3 · 记得 KNOWN（⌘3）

**定位**：小6的全部积累，一个入口。
**频率**：★★★☆☆

| 二级 | 内容 | 数据源 | 现状 |
|---|---|---|---|
| 记忆 | 34 条长期记忆 + 检索 | `memory.py` + `memory_query.py` | ✅ 已有可复用 |
| 知识 | **46 篇文档 / 35 条关系** | `knowledge/` + manifest | 🆕 **完全不可见** |
| 关系图 | 记忆↔知识↔目标 拓扑 | `galaxy-state.js` 投影 | ♻️ Galaxy 重生于此 |
| 对话史 | 历史会话 | `chat_log` | ♻️ 从"独立软件"降级为此处一个视图 |
| 画像 | 用户模型 | `user_model`（0 行） | ⚠️ 空表，暂不给入口 |

**合并理由**：对用户而言"记忆"与"知识"的边界是工程概念，不是心智概念。用户只问一句：**"小6记得什么？"** 内部区分（memories 表 vs md 文件）保留在实现层。

---

### 焦点 4 · 在看 SENSING（⌘4）

**定位**：小6替你盯着的世界。
**频率**：★★★☆☆（数据显示这是历史最高频，514 条推送）

| 二级 | 内容 | 数据源 | 现状 |
|---|---|---|---|
| 洞察收件箱 | 主动推送流 | `pending_proactive`（514 行） | 🆕 **无消费 UI，引擎已停摆** |
| 热点 | 实时热点 | `hotspots.py`（354 条） | ✅ 已有（hotspot.js 1881 行） |
| 天气环境 | 天气/地理 | `geo_weather.py` | ✅ 已有 |
| 系统监控 | CPU/内存/进程 | `sysmon.py` | ✅ 已有，降级为按需 |
| 免打扰 | DND / 推送策略 | `/api/proactive/dnd` | ⚠️ 有 API 无 UI |

**修复优先级 P0**：主动引擎停摆 6 天（08-04 后无新增）。**这是小6最高频的价值来源，必须先修引擎再谈 UI。**

---

### 焦点 5 · 是谁 SELF（⌘5）

**定位**：小6的自我 —— 它是谁、能做什么、被允许做什么。
**频率**：★★☆☆☆

| 二级 | 内容 | 数据源 | 现状 |
|---|---|---|---|
| 人格 | 名字/语气/称呼 | `persona_engine.py` | ✅ 已有 |
| 能力 | 62 工具，**标注真实/Mock** | `capabilities.py` + `capability_registry.py` | ♻️ 重构 |
| 授权 | 四级权限（auto/confirm/session/never） | `policy_engine.py` | ⚠️ 有后端无 UI |
| 模型 | Provider / 模型选择 | `provider_registry.py` | ✅ 已有 |
| 系统 | 主题、快捷键、数据导入导出 | `settings.js` | ✅ 已有，需瘦身 |
| 自检 | 健康与诊断 | `self_check.py` | ✅ 已有 |

**设计纪律（P0）**：能力清单必须**显式区分真实与 Mock**。当前 `permission_guard` 走 `MockComputerExecutor`，13 个声明能力仅 7 个实现 —— 把假能力和真能力平级陈列，是信任崩塌的起点。

```
✅ 读取文件         可用
✅ 网页抓取         可用
⚠️ 打开应用         模拟（未接入真实执行器）
🔒 执行命令         未实现
```

## 6. 频率 × 深度矩阵

用于校验"高频能力是否够浅"。

| 能力 | 日频次 | 触达深度 | 判定 |
|---|---|---|---|
| 看 AI 状态 | 极高 | **0 层**（永远可见） | ✅ |
| 说一句话 | 极高 | **0 层**（意图行常驻） | ✅ |
| 看今日态势 | 高 | **0 层**（NOW 默认） | ✅ |
| 看主动洞察 | 高 | 1 层（⌘4） | ✅ |
| 看/改目标 | 中高 | 1 层（⌘2） | ✅ |
| 查记忆 | 中 | 1 层（⌘3） | ✅ |
| 看知识文档 | 中 | 2 层（⌘3 → 知识） | ✅ |
| 看关系图 | 低 | 2 层（⌘3 → 关系图） | ✅ |
| 改设置 | 低 | 2 层（⌘5 → 系统） | ✅ |
| 看系统监控 | 极低 | 2 层（⌘4 → 监控） | ✅ |

**规则：日频 ≥ 中高的能力，触达深度必须 ≤ 1 层。** 全部达标。

**对比现状**：目标管理频次应为"中高"，当前深度 = **∞（无入口）**。这是 v2 修复的头号缺口。

## 7. 与红线的逐条核对

| 红线 | 本 IA 的兑现方式 |
|---|---|
| 最多 5 个一级导航 | 恰好 5 个焦点 |
| 禁止 Home/Workspace/Assistant/Galaxy/Settings 式菜单 | 全部改为 AI 注意力状态命名 |
| 禁止多首页 | 唯一默认态 = NOW，无第二首页 |
| 禁止页面跳转感 | 焦点切换为同空间注意力转移（见 03 文档） |
| Chat 不是独立软件 | 降级为常驻 Intent Line |
| Galaxy 不是主页 | 移出一级导航，降为 KNOWN 下的视图模式 |
| 禁止大量后台面板 | 11 浮层 → 分层浮层体系（见 04 文档） |
| 功能入口简单 | 5 焦点 + 1 输入行，高频能力 ≤ 1 层 |
