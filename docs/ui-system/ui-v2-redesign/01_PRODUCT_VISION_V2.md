---

## 1. 一句话定位

> **小6是一个住在你电脑里的智能体。
> 你不"使用"它，你和它一起工作。**

这句话决定了后面所有设计决策。它排除了三件事：

- ❌ 不是工具箱 —— 工具箱按功能分格子，智能体按注意力组织
- ❌ 不是聊天窗 —— 聊天窗只有话，智能体有状态、有记忆、有正在做的事
- ❌ 不是仪表盘 —— 仪表盘展示数据，智能体承担责任

---

## 2. 三层认知模型

新用户和老用户都必须在同一条时间轴上被满足。

### 1 秒 —— 看到"它在"

打开小6的第一帧，屏幕上只有一件东西是亮的：**AI 的存在本身**。

```
                    ◍
              （呼吸中的核心）

              我在。今天有 3 件事。
```

**1 秒内必须传达的唯一信息：AI 是活的、在线的、有状态的。**

- ✅ 一个会呼吸的核心（Presence Core），颜色随状态变化
- ✅ 一句它主动说的话（不是 placeholder，是它对今天的判断）
- ❌ 不是星空 —— 星空说明不了 AI 是否在线
- ❌ 不是菜单 —— 菜单要求用户先做选择题
- ❌ 不是空的输入框 —— 空输入框把责任推回给用户

> **设计判据**：截图给一个没用过小6的人看 1 秒，他应该说出"这个 AI 在等我"，
> 而不是"这是个天文软件 / 这是个聊天软件 / 这是个后台系统"。

### 5 秒 —— 理解"它知道什么、能做什么"

视线自然下移，用**不超过三块信息**说清全局：

```
                    ◍  待命

         早上好。昨晚的爬虫任务完成了，
         抓到 12 条；今天 14:00 有复盘。

    ┌──────────────┬──────────────┬──────────────┐
    │ 在做  2      │ 记得  34     │ 在看  3 条   │
    │ 爬虫 · 复盘   │ 最近：定价策略 │ 热点 · 天气   │
    └──────────────┴──────────────┴──────────────┘

    ▸ 对小6说点什么…                        ⌘K
```

**5 秒内必须建立的认知：**

| 认知 | 承载元素 |
|---|---|
| 它记得我 | 主动摘要里出现昨天的事 |
| 它在替我盯着 | "在做"里有正在跑的任务 |
| 它有积累 | "记得"的数字在增长 |
| 我怎么指挥它 | 底部那一行，永远在 |

**关键设计**：这三块不是导航按钮，是**AI 的自述**。它在说"我手上有 2 件事、我记住了 34 条、我替你盯着 3 个信号"。点进去才是导航。

### 30 秒 —— 完成一件真事

30 秒内，用户必须**完整走通一次价值闭环**，且全程不离开当前空间。

```
 0s   打字：帮我盯一下竞品这周的定价变化，有变动告诉我
 3s   ◍ 转为 PLANNING，意图行下方就地展开理解结果：
        ┌────────────────────────────────────┐
        │ 我理解为一个持续目标                 │
        │ 目标：监控竞品定价                   │
        │ 频率：每天 09:00    通知：有变动时    │
        │ 首次执行：现在                       │
        │              [ 就这样 ]  [ 改一下 ]  │
        └────────────────────────────────────┘
12s   点「就这样」→ ◍ 转 EXECUTING，执行流就地滚动
        · 搜索竞品页面      ✓ 3 个来源
        · 提取价格           ✓ 12 条
        · 与上周对比         ✓ 2 项变化
25s   结果卡片就地生成 + 「已记住 · 明早 09:00 再跑」
30s   核心回到 IDLE，"在做"计数 +1
```

**30 秒结束时用户获得的四样东西：**

1. 一个**结果**（现在就能看的对比）
2. 一个**承诺**（明早还会跑）
3. 一条**记忆**（小6记住了我关心定价）
4. 一次**信任**（它没让我填表单、没让我切页面）

> **零页面跳转** 是这段体验的硬指标。从输入到结果，`body` 上不应发生任何模式类切换。

## 3. Daily AI Workflow

真实的一天，不是一次性演示。

### 晨（打开电脑）

```
◍ 主动开口 ——
   "昨晚 3 个任务跑完 2 个，爬虫在 02:14 失败了（超时）。
    今天 14:00 复盘。要我先重跑爬虫吗？"
                                    [ 重跑 ]  [ 待会 ]
```

**要点**：AI **先说话**，且说的是判断不是问候。"早上好"是废话，"爬虫失败了"是价值。

### 午（工作中）

```
⌘Space  →  意图行浮起（全局唤起，不切页面）
        →  "把刚才那个报错记下来，明天查"
        →  ◍ 就地确认：已记入 · 明天 09:00 提醒
        →  Esc 关闭，回到原本在做的事
```

**要点**：**唤起 → 说 → 关闭** 三步内完成，小6从不要求用户"进入"它。

### 晚（收尾）

```
◍ "今天你说了 4 次'定价'。要我把它变成一个长期目标吗？"
                                    [ 好 ]  [ 不用 ]
```

**要点**：这是 `learnings` 表（23 条）与 `goal_decision_engine.py` 已经具备、但从未被用户看见的能力。**AI 从对话里长出目标**，而不是让用户去填一个"新建目标"表单。

### 夜（无人值守）

```
scheduler + proactive TICK 持续运行
成果沉淀为：新记忆 / 任务状态变化 / 待呈现洞察
   ↓
明晨第一帧的那句主动开口
```

**闭环成立**：晚上的自主运行，产出的正是第二天早上"1 秒认知"的内容。**小6的一天是个环，不是一串会话。**

## 4. 体验原则（可用于评审打分）

| # | 原则 | 反面示例（当前系统） |
|---|---|---|
| 1 | **AI 先开口** | 现在首屏是静默的英雄区标语 |
| 2 | **零页面跳转** | 现在 chat/universe/cp 四选一互斥切换 |
| 3 | **就地展开** | 现在结果分散在遥测栏、时间线、聊天区三处 |
| 4 | **状态永远可见** | 现在 AI 状态藏在 HUD 一个小药丸里 |
| 5 | **能力自证** | 现在能力矩阵是静态清单，不说明"能为你做什么" |
| 6 | **假能力不占位** | 现在 Mock 的电脑操作与真能力平级陈列 |
| 7 | **不让用户填表** | 现在目标系统若暴露，默认会是 CRUD 表单 |
| 8 | **沉默比装饰好** | 现在有月球公转、扫描线、9 色主题 |

## 5. 首屏内容优先级（屏幕预算分配）

以 1920×1080 首屏为基准，**视觉重量**分配：

| 层级 | 内容 | 占比 | 说明 |
|---|---|---|---|
| **主角** | AI Presence Core + 主动开口 | **45%** | 屏幕正中偏上，绝对视觉中心 |
| **次角** | 今日态势三块（在做/记得/在看） | 20% | 核心下方，一行三列 |
| **常驻** | Intent Line 意图行 | 12% | 底部，永远存在，永远聚焦可用 |
| **边缘** | 焦点脊柱（5 焦点） | 8% | 左侧极窄，图标为主 |
| **环境** | 氛围背景（非天文） | 15% | 极低对比度，纯呼吸感 |

**与现状对比：**

| 元素 | 现状占比 | v2 占比 |
|---|---|---|
| 天文背景 | ~60%（全屏 + 6MB 资源） | **0%** |
| AI Presence | ~8%（一个小 canvas + 药丸） | **45%** |
| 主动内容 | ~0%（Insight 面板常空） | **20%** |
| 静态品牌标语 | ~15%（三重小6 + 英雄区文案） | **2%** |

> **一句话：把 60% 的天文预算，转给 AI 本身。**

## 6. 验收问句

设计定稿前，逐条回答。任何一条答"否"，方案不通过。

- [ ] 遮住 logo，用户能否在 1 秒内说出"这是个 AI"？
- [ ] 首屏第一句话，是 AI 说的，还是产品文案？
- [ ] 用户完成第一件真事，中途切换了几次空间？（必须为 0）
- [ ] AI 的状态（思考中/执行中/等待）是否在任何焦点下都可见？
- [ ] 关掉小6一夜再打开，它是否能证明"我这一夜在替你干活"？
- [ ] 屏幕上是否还有任何元素，删掉之后用户不会察觉？（有则删）
