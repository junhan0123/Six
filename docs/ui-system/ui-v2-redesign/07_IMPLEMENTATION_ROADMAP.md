## 1 · 实施总原则（先于一切具体动作）

1. **替换，不叠加**：v2 用**单一 `ui.v2.css`** 一次性替换 `ui2→ui5d` 五代文件。`06` §7 的 Token 是唯一定义源。不再新增任何 `ui6x-*` 覆盖层。
2. **状态层单一事实**：废除 `body.chat-mode / universe-mode / cp-mode` 互斥模式类，全系统只新增 **`body[data-focus]`**（取值 `now/doing/known/sensing/self`），由 `03` 定义。
3. **真资产继承，假资产删除**：后端 66 API / 62 工具 / `galaxy-state.js` 数据层 / `ui2.css` 的 z-index·圆角·缓动 = 继承；天文渲染 / 五代覆盖 / `scale()` 骗局 = 删除。
4. **诚实优先**：Mock 能力与真实能力**不**平级陈列（`04` SELF 屏、`06` §5 红线 5）。

## 2 · P0 · 必须先修的产品缺陷（非 UI，但阻塞验收）

审计发现 4 个"后端/数据已存在但前端零暴露或已停摆"的硬伤。它们不是 v2 的新功能，而是**把已有能力接上来的前提**。不修，v2 屏幕会是空的。

| # | 缺陷 | 证据 | 动作 | 验收关联 |
|---|---|---|---|---|
| P0-1 | **主动引擎停摆 6 天** | `pending_proactive.py` 514 行，`SENSING` 屏无活信号 | 排查停摆根因（调度/异常吞没），恢复主动推送 | SENSING 屏有内容 |
| P0-2 | **Goal System 后端完整、前端为零** | 后端 `goals.py` 完备，`server.py` 从不 `import goals` | 补 `/api/goals` REST 层（v2 **唯一**后端改动），前端接 `DOING` 屏 | DOING 屏有任务 |
| P0-3 | **46 篇知识文档不可见** | `knowledge/` 目录 8 类 46 篇 md，无前端入口 | 建目录树读取接口，接 `KNOWN`「知识」视图 | KNOWN 屏有知识 |
| P0-4 | **Mock 能力与真实能力平级** | `permission_guard.py:40` `executor or MockComputerExecutor()` | `SELF` 屏标注每能力真实/Mock（角标），不伪造 | 信任风险消除 |

> P0 与 UI 重写可并行启动，但 **P0-2 / P0-3 的数据接口契约必须在 P1 前冻结**，否则屏幕规格会返工。

## 7 · 风险与"不要做"清单

| 风险 | 触发条件 | 规避 |
|---|---|---|
| 五代 CSS 借尸还魂 | 实施者为赶进度又叠一层 `ui6x` | 强制删除五代文件（P1-6），CI 检查无 `ui[2-5]*` 引用 |
| 模式类死灰复燃 | 习惯写 `body.classList.add('chat-mode')` | 全局搜索 `*-mode` 类，仅允许 `data-focus` |
| 天文"暗壁纸"伪装回归 | 把太阳系调暗当背景 | P1-2 已删 `solar-system.js`，无贴图可引 |
| 伪响应式回潮 | 重新 `scale()` 整页 | P1-1 删除，用 Grid+clamp |
| Mock 冒充真实 | SELF 屏不标角标 | P0-4 强制角标，PR 检查 |
| 主动引擎再次静默 | 恢复后无监控 | P0-1 恢复时加心跳日志 + SENSING 屏空态告警 |
