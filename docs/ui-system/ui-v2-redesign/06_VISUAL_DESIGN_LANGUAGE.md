# 06 · 视觉设计语言（Phase 5）

> **阶段纪律**：`ONLY DESIGN`。本文定义 v2 的视觉 Token 体系与原则，**不写 CSS、不改 `ui2.css`、不碰任何渲染代码、不提交 Git**。现有 `ui2.css` 的 270 个 Token 是"待裁剪的起点"，不是"待覆盖的对象"——v2 要**替换**五代叠加，而非再叠一代。

---

## 0 · 设计取向（先定调，再定色）

四个参照物，各取一段，不许抄皮：

| 参照 | 借什么 | 不借什么 |
|---|---|---|
| **Apple Vision Pro** | 空间层级感、环境光、景深而非边框 | 不借"玻璃拟态卡片堆叠"——那是当前 4D/5D 的失败味 |
| **Linear** | 信息密度、精确间距、克制的强调色、键盘优先的秩序感 | 不借"项目管理后台"的栏目感 |
| **Raycast** | 命令即入口、单一输入行统御全局、结果为王的留白 | 不借"启动器"的临时感——小6是常驻 OS 不是弹出框 |
| **Jarvis** | AI 在场感、环境化而非界面化的"智能环绕" | 不借"炫技 HUD 动画"——扫描线/粒子/无意义转场一律禁 |

**一句话定位**：*Precision（Linear 的精确）× Ambient（Vision Pro 的空间）× Command（Raycast 的意图行）× Presence（Jarvis 的在场）*，落在一个**深色优先、单一空间、AI 常驻**的画布上。

---

## 1 · 颜色系统（深色优先，单色温主调）

### 1.1 基底哲学
- **深色优先（Dark-first）**：AI OS 是常驻环境，深色降低持续注视疲劳，也最出"科技感"。提供完整的 Light 变体，但 Dark 是主交付。
- **单主色温**：全系统只用一个强调色（青蓝 `—accent`），其余皆为中性灰阶。禁止"彩虹分类"——goal/agent/task/memory/knowledge 不用 5 种颜色区分，而用**同一色相的不同明度/透明度**区分，保持"它们是同一个 AI 的不同面向"的心理暗示（呼应 03「AI 没变」原则）。

### 1.2 中性灰阶（Web 安全，深→浅）
```
--bg-void      #0A0C10   // 环境底（L0 环境层）
--bg-ground    #0F1218   // 主画布（L1/L2 承载面）
--bg-raised    #161A22   // 浮起面（意图行/侧栏）
--bg-hover     #1E232E   // 悬停
--line-soft    #232936   // 分隔线（极细，1px，低对比）
--line-strong  #2E3645   // 聚焦边框
--text-dim     #8A93A6   // 次级文字
--text-base    #C7CEDB   // 正文
--text-bright  #EEF2F8   // 标题/强调
```

### 1.3 强调色（唯一）
```
--accent       #4DA3FF   // 青蓝，AI 在场 / 可操作 / 焦点
--accent-soft  #4DA3FF22 // 16% 透明，作辉光/选中底
--accent-warn  #FFB454   // 仅用于"需人工确认"类（Mock 能力、待办）
--accent-bad   #FF6B6B   // 仅用于失败/风险
```
> 强调色克制使用：**全屏同时只有 ≤1 处实心强调**。其余用 `accent-soft` 透明辉光表达"这里与 AI 有关"。

### 1.4 语义明度（同色相、不同明度区分实体，而非不同色相）
| 实体 | 表达 | 视觉 |
|---|---|---|
| goal 目标 | 实心 accent | ● |
| agent 智能体 | accent 80% 明度 | ◐ |
| task 任务 | accent 60% | ○ |
| memory 记忆 | 中性 text-base | □ |
| knowledge 知识 | 中性 text-dim | ▢ |
> 记忆与知识用中性灰（它们属于"用户世界"，不是"AI 世界"），goal/agent/task 用 accent 梯度（属于"AI 世界"）。一眼区分"小6在想什么" vs "小6记住了什么"。

### 1.5 来自 `ui2.css` 的继承与裁剪
- ✅ 继承：14 级 z-index 阶梯（`--z-ground`…`--z-top`）—— 这是五代叠加里**唯一做对的基础设施**，v2 直接复用为 L0–L4 层级的锚。
- ✅ 继承：5 级圆角（`--r-xs/sm/md/lg/xl`）。
- ✅ 继承：统一缓动变量（如 `--ease-out` / `--ease-spring`）。
- ✂️ 裁剪：270 个 Token 中约 40% 是五代叠加遗留的"一次性覆盖色"（如 `ui4d-*` / `ui5d-*` 专用变量），v2 全部废弃，归并回上表主体系。

## 2 · 空间系统（间距、栅格、层级）

### 2.1 间距标尺（4px 基数，封顶）
`--s-1:4 / --s-2:8 / --s-3:12 / --s-4:16 / --s-5:24 / --s-6:32 / --s-7:48 / --s-8:64`
> 禁止任意像素。所有 padding/margin/gap 取标尺值。当前代码里 `padding:13px` `margin:27px` 这类"手感值"一律归位。

### 2.2 布局栅格（统一空间，不是多页）
- v2 是**单一画布**，靠 `body[data-focus]` 置换 L2 焦点区，而非切换页面。
- 主画布固定安全区：左右 `--s-7`(48) 留白，顶 `--s-6`(32)（给常驻核心留呼吸）。
- **禁止伪响应式**（`index.html` 1546 行的 `scale(baseW/baseH)` 骗局必须删除）：v2 用真实 CSS Grid + `clamp()` 流式适配 1280–2560 宽，不再等比缩放整页。

### 2.3 层级映射（与 03 四层模型对齐）
| 层 | z-index 锚 | 视觉 |
|---|---|---|
| L0 环境 | `--z-ground` | 纯色底 + 极弱径向辉光（非天文、非贴图） |
| L1 在场 | `--z-base` | AI 核心常驻 |
| L2 焦点 | `--z-raised` | 当前焦点内容区 |
| L3 意图 | `--z-dock` | 意图行（常驻输入） |
| L4 瞬时 | `--z-modal`…`--z-top` | toast / 确认框 / 命令面板 |

## 3 · 字体系统

### 3.1 字体族
- **界面/正文**：系统无衬线栈（`-apple-system, "PingFang SC", "Microsoft YaHei", system-ui`）—— 不引外部字体，零加载成本，中文渲染优先。
- **数据/代码/数字**：等宽栈（`"SF Mono", "JetBrains Mono", ui-monospace`）—— 用于目标 ID、时间戳、状态值，强化"机器感"可信度。
- **禁止**衬线标题、艺术字、渐变文字。

### 3.2 字阶（类型标尺）
```
--t-display 28/32  // 首屏核心名（仅 1 处）
--t-title   20/26  // 焦点区标题
--t-sub     15/22  // 区块标题
--t-body    14/21  // 正文（默认）
--t-cap     12/16  // 标签/元信息（大写字母间距 0.04em）
--t-mono    13/20  // 数据
```
> 字阶 ≤ 6 级。当前五代 CSS 里 `font-size:11px/13px/15px/18px/22px/28px/34px` 散落，v2 全部收口到上表。

### 3.3 字重纪律
- 全系统只用 **400（正文）/ 500（强调）/ 600（标题）** 三档。
- 禁止 700+ 粗体喊话；强调靠**颜色 + 间距**，不靠加粗。

## 4 · 动效系统（克制，有目的地动）

### 4.1 统一缓动（继承 `ui2.css` 变量，封顶时长）
```
--ease-out:   cubic-bezier(.22,.61,.36,1);
--ease-spring:cubic-bezier(.34,1.56,.64,1);  // 仅用于焦点落位
```
- **焦点转移 ≤ 420ms**（与 `03` 一致）：L2 焦点置换用 transform + opacity，禁止重排（reflow）。
- **常驻元素零位移**：AI 核心（L1）在五焦点间只做 transform 移动，永不重建 DOM（呼应"AI 没变"）。

### 4.2 允许 vs 禁止
| 允许 | 禁止（炫技） |
|---|---|
| 焦点区淡入/上移 8px（≤420ms） | 扫描线、粒子流、星空旋转 |
| 意图行展开/收起（height/opacity） | 3D 翻页、卡片堆叠翻转 |
| 状态变更的微辉光（accent-soft 呼吸） | 全屏转场幕布、无意义 loading 动画 |
| 列表项 hover 底色过渡（120ms） | 弹跳、果冻、视差滚动 |

> 动效的唯一判据：**它是否在告诉用户"AI 的状态/位置变了"？** 是则留，否则删。

## 5 · 组件原则（六条红线）

1. **禁止玻璃卡片堆叠**：不用 `backdrop-filter` 多层叠加。一个面只有"底 + 1px 细线"，层次靠明度差而非模糊。
2. **禁止网页后台感**：不用传统顶栏+侧栏+内容区"三明治"栏目标签。导航是 Focus Spine（⌘1–⌘5），不是菜单。
3. **禁止炫技动画**：见 4.2。
4. **单一强调**：全屏同时 ≤1 处实心 accent（1.3）。
5. **诚实视觉**：Mock 能力用 `--accent-warn` 角标（如"演示"），真实能力无角标；空数据显"暂无"，不造热闹。
6. **密度优先于装饰**：默认信息密度高（Linear 风），留白用于"呼吸"而非"填背景图"。

## 6 · 首屏视觉预算（落实 `01` 的 60% 转移）

`01` 提出"把 60% 天文预算转给 AI"。落到颜色/空间：

| 区域 | 旧预算（天文） | 新预算（AI 核心） |
|---|---|---|
| 背景 | 4.7MB 贴图 + 着色器辉光 | `--bg-void` + 1 处径向 `accent-soft` 8% 辉光（CSS，0 成本） |
| 视觉重心 | 太阳系中心（半径 13–98） | AI 核心（L1，首屏 45% 面积） |
| 强调 | 行星彩色 | 单一 accent + 核心辉光 |
| 动效 | 公转/自转（持续 GPU） | 核心呼吸（CSS，idle 时停） |

> 净效果：视觉"科技感"不降反升——因为重心从"遥远的星星"回到"眼前的 AI"。
