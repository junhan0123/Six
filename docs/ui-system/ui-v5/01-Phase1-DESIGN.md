# Phase 1 · v5 UI 设计规范

> 设计语言与 v4 彻底断开。v4 偏「极简安静」；v5 偏「有生命的存在感」——更聚焦、更空间化、更具未来 AI OS 质感。结构同「一个空间 / 一个核心 / 一个入口」，但视觉重写。

## 一、产品定位（重申）

小6 = 用户打开电脑后一直存在的本地 AI 副驾。不是聊天机器人、不是 Dashboard、不是工具集合、不是太阳系展示。

打开首屏第一感觉应是：**「小6就在这里」**，而非「这里有什么功能」。

## 二、空间结构（Presence Space）

```
┌──────────────────────────────────────────────┐
│  小6 ●                            12:48        │  ← 顶部：仅品牌 + 活体点 + 时间
│                                                │
│                                                │
│                   ◉  AI Core                   │  ← 视觉绝对中心（光核+能量环+微粒）
│                  （Voice 环 贴附）              │
│                                                │
│               小6 / 当前状态 / 当前任务         │  ← 身份区（人话）
│                                                │
│            正在 …   记得 …   理解 …             │  ← Context Layer（自然表达，无卡片）
│                                                │
│                                                │
│            ┌────────────────────────┐          │
│            │ 告诉小6你想做什么      ⏎ │          │  ← Intent Line（唯一入口）
│            └────────────────────────┘          │
│                                                │
│   ·记忆 ⌘1   ·知识 ⌘2   ·目标 ⌘3   ·世界 ⌘4     │  ← Ambient 快捷（hover 显字）
└──────────────────────────────────────────────┘
```

## 三、AI Core（最高优先级 · 灵魂）

### 视觉构成（从内到外）
1. **光核 nucleus**：径向渐变 + 内禀光泽流转（shimmer），呼吸尺度。
2. **能量环 halo**：细环，缓慢自转 + 随状态脉动。
3. **扫掠环 ring**：conic 遮罩扫掠（活跃态加速）。
4. **微粒 particles**：环绕粒子轨迹（执行/思考态更明显、更快）。
5. **外晕 aura**：大半径柔光，呼吸。

### 8 态表现（颜色取自 avatar-state.META，唯一来源）

| 态 | 颜色 | 亮度 | 微粒 | 速度 | 文案 |
|---|---|---|---|---|---|
| IDLE | `#5fb3c8` | 静 | 隐 | 慢 | 在这里，随时开始 |
| WAITING | `#f0b35e` | 中 | 微 | 中 | 等你确认一下 |
| THINKING | `#8b9bff` | 亮 | 中 | 快 | 正在理解你的需求 |
| PLANNING | `#c08bff` | 亮 | 中 | 中快 | 正在把它拆开 |
| EXECUTING | `#56d364` | 最亮 | 显 | 最快 | 正在做 |
| COMPLETED | `#56d3a0` | 柔 | 微 | 慢 | 刚做完一件事 |
| ERROR | `#ff6b6b` | 警示脉冲 | 隐 | 急 | 卡住了，想请你看一眼 |
| OFFLINE | `#8a93a6` | 灭 | 隐 | 停 | 暂时离线 |

**关键**：不只是换色。每个态改变 亮度（glow 强度）、微粒可见度与数量感、运动速度（呼吸/扫掠/自转周期）。

## 四、顶部区域（极简降噪）

- 左：`● 小6`，圆点为「活体存在点」——颜色随 AI Core 态、呼吸节奏随态；离线变灰静止。
- 右：等宽字体时间 `--:--`，极淡。
- **删除**：「AI OS」「Presence Space」等所有自述文字。品牌不解释。

## 五、Context Layer（自然语言，禁卡片/数字）

三行，行内 `<em>` 强调实体，无卡片、无数字、无百分号、无英文 slug：

- **正在**：当前目标（进展措辞：刚开了个头 / 推到一半了 / 快收尾了…）。
- **记得**：最重要的一条记忆（去机器前缀）。
- **理解**：系统由哪些部分构成（Agent Runtime / Memory / Knowledge / Intent Gateway…）。

空态用人话（如「我还在了解你」）。

## 六、Intent Line（唯一输入入口）

- 底部居中单输入，Raycast + Claude 气质：圆角胶囊、聚焦柔光 + 1px 上浮。
- 状态文案随 AI Core 态变化（等待 / 思考中 / 执行中…）。
- 提交 → `ZZIntentGateway.dispatch(text)` → `/api/agent/intent`（与语音同一链路）。
- 中文输入法保护：`compositionstart/end` 拦截 Enter 误提交。
- 不建消息列表、不建历史面板。

## 七、Voice Core（语音不是按钮，是感知入口）

- 贴附 AI Core（核心右下方），与核心同一设计语言（柔光 + 呼吸 + 声音响应）。
- 五态（`data-voice` 与 AI Core `data-state` **正交共存**）：
  - **idle**：极淡静止，仅微光暗示可唤醒。
  - **listening**：外围波纹扩散（多层 ring scale/opacity 循环）。
  - **thinking**：频率变化（波纹节奏变快、抖动）。
  - **speaking**：声波向外扩散（sonar）。
  - **error**：红色警示脉冲。
- 数据连接：`/api/asr`（后端 FunASR/Vosk/Whisper）+ 浏览器 `SpeechRecognition(zh-CN)` 降级 + `wakeword_detected` SSE 唤醒。
- 识别文字 → 实时填入 Intent Line（`setText`）→ 用户确认后随 Intent Line 发送。不建第二个聊天框。

## 八、World Map（放弃太阳系，保留关系理解）

- 数据来源 `/api/memories/graph`（复用 galaxy-state 的同一种关系数据）。
- SVG 2D 轻量关系网络：节点 = 项目/知识/记忆/任务；边 = 关联。
- **默认隐藏**，仅 ⌘4 / 世界快捷键打开 Overlay 内展示。不展示为星系/3D。

## 九、Overlay（Spotlight 式能力展开）

- ⌘1 记忆 / ⌘2 知识 / ⌘3 目标 / ⌘4 世界 / ⌘5 关于。
- 居中浮层（scrim + sheet），非页面跳转、非新窗口。
- 每类首行一句小6引导语（「我记住的」「我读过的」「我在推进的」「我理解的」「关于我」），行式列表，hover 仅极淡提亮。
- 焦点管理：打开聚焦关闭键、关闭归还原焦点、Esc 关闭。

## 十、视觉规范

- **Dark First**：背景 `#06070b`（接近黑、非纯黑，保留纵深）。
- **唯一强调色**：AI 状态色（由 `--core-*` 变量驱动，100% 来自 avatar-state）。
- **禁**：多彩主题、玻璃卡片墙、边框堆叠、渐变背景、星空装饰、数据墙、左侧菜单、多页面。
- **字体**：系统无衬线（中文优先）；数据/时间用等宽。
- **空间**：大量留白；中央核心为绝对焦点。
- **动效**：克制微动效（呼吸、扫掠、波纹、聚焦柔光）；尊重 `prefers-reduced-motion`。

## 十一、红线自检

| 红线 | 遵守方式 |
|---|---|
| 不新增 Runtime | 不写任何 runtime；只消费 `/api/*` 与 SSE |
| 不新增 Event | 仅订阅既有 `agent_state` + `wakeword_detected` |
| 不修改 Agent | 不动 `agent_runtime.py` |
| 不恢复旧导航/Galaxy/Dashboard/聊天 | 结构全新，无上述元素 |
| 不污染旧代码 | 旧文件只读引用；仅 server.py 追加一行静态路由 |

→ 全部可遵守。进入 Phase 2 构建。
