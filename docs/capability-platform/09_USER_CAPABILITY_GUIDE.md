# 09 · 用户能力指南（User Capability Guide）— Stage I

> 站在**用户角度**：小6能干什么、怎么用、在哪里、什么时候用、哪些自动、哪些需命令、哪些需授权、哪些需配置。

---

## 一、小6能为你做什么（能力地图）

### 💬 对话与问答
- 自然语言聊天、追问、总结、翻译、写作。
- **入口**：主界面输入框 / 伴侣气泡"对小6说"。
- **自动**：是。

### 🧠 记忆与个性化
- 记住你的偏好、习惯、重要日期、长期事实。
- 自我学习（从反馈中萃取经验）。
- **入口**：对话中自然表达即可（"记住…""每年 X 提醒我…"）。
- **查看**：指令中心 → "查询长期记忆" / 记忆网络面板。
- **自动**：是（对话即记）。

### 📚 知识库
- 基于 Obsidian 笔记的结构化知识检索（关键词）。
- **入口**：直接提问；或"文档库"面板。
- **配置**：指令中心 → "知识平台"开关（`FEATURE_KNOWLEDGE_PLATFORM`）。
- **注意**：当前为**关键词检索，非语义理解**；复杂语义问答可能命中不足。

### 🎯 目标与任务
- 让小6"去做一件事"：建目标 → 拆解步骤 → 逐步执行 → 完成反思。
- **入口**：对话中表达意图（如"帮我调研 X"）；或指令中心 → "新建目标"。
- **自动**：意图网关会自动判定是否建目标。
- **授权**：电脑类动作需你**确认**（见下文"授权"）。

### 🖥️ 电脑控制（最小副作用）
- 读文件、截图(内存)、看窗口/进程、打开应用、聚焦窗口、浏览器导航。
- **入口**：对话中要求（"打开 XX 应用""截个图"）。
- **授权**：开应用/聚焦/导航需**你确认**；高危操作（改文件/执行命令/杀进程/删除/系统/网络）**当前默认拒绝**（占位，未开放）。
- **状态**：读/截图/枚举为生产；开应用等为确认制。

### 🔔 主动智能（Proactive）
- 后台自动：舆情、天气异常、目标截止提醒、周小结、IFTTT 规则等。
- **自动**：是（后台 tick）。
- **控制**：指令中心/设置 → "主动智能 V2"开关；伴侣菜单 → "勿扰"。
- **通知**：洞察面板 / 伴侣气泡弹出。

### 🌐 外部信息
- 天气、台风、地图、系统监控、热点、每日简报。
- **入口**：指令中心面板 / 对话提问 / 主界面按钮(天气/热点/简报)。
- **自动**：每日简报可自动推送（若开启）。

### 🔗 社交（需配置）
- 飞书/Discord/企业微信 出站与入站。
- **状态**：默认未配置（需填密钥）。
- **入口**：对话要求发送；或配置后入站自动触发。

### 🎙️ 语音
- 语音输入(麦克风)、唤醒词、语音合成(TTS)。
- **入口**：主界面麦克风按钮；设置 → 唤醒词/自动朗读。
- **状态**：依赖本地模型，缺失时降级。

### 🛠️ 开发者/自检
- 能力清单、工具审计、模型测试、自检测页。
- **入口**：设置 → 自检；`/api/capabilities` 等（开发者用）。

## 二、怎么用（操作速查）

| 想做 | 怎么做 | 入口 |
|---|---|---|
| 聊天 | 输入文字 / 说给伴侣 | 输入框、伴侣气泡 |
| 打开命令中心 | Ctrl/Cmd+K | 指令中心 |
| 打开设置 | 点设置按钮 / 按 `,` | 设置面板 |
| 新建目标/待办/提醒 | 指令中心 → 创建 | 指令中心 |
| 查记忆/知识 | 指令中心 → 面板 | 各面板 |
| 看天气/热点/简报 | 点按钮或指令中心 | 按钮 / 指令中心 |
| 让小6执行任务 | 对话表达意图 | 对话 |
| 开应用/截图 | 对话要求 | 对话（需确认） |
| 开/关某功能 | 指令中心 → 功能 / 设置 | 开关 |

## 三、哪些能力自动 / 需命令 / 需授权 / 需配置

| 类型 | 能力 |
|---|---|
| **自动（无需操作）** | 对话记忆、主动智能扫描/通知、文件监听重载、任务恢复、自检测 |
| **需命令/点击** | 目标/待办/提醒创建、各面板打开、主题切换、功能开关、语音输入 |
| **需授权（确认）** | 电脑：开应用/聚焦/导航（confirm）；所有高危电脑操作（默认拒绝） |
| **需配置（密钥/flag）** | 社交(飞书/Discord)、媒体生成(MiniMax)、ASR/KWS 模型、日历/焦点/剪贴板感知、跨端、常驻、移动端 |

## 四、你可能不知道的能力（隐藏/实验）

- **移动伴随端(PWA)**：默认关（`FEATURE_MOBILE_COMPANION`），开后用手机访问简报/提醒/对话。
- **常驻伴随(always-on)**：默认关，开后可桌宠常驻。
- **跨端接力**：默认关，开启后可设备间交接会话。
- **工具工厂 / Agent 委托**：默认关，开发者实验。
- **感知(UIA/OCR/Vision)**：当前为 Mock，暂不可用于真实识别。
- **周期调度器**：已实现但**未接线**，当前无入口。

---

## 五、使用建议

1. 善用**指令中心(Ctrl+K)**：它是唯一命令入口，所有面板/功能/创建都在这里。
2. 电脑操作**放心描述**，小6会先确认高风险动作。
3. 知识库用**结构化笔记**，关键词检索对标题/标签敏感。
4. 不想要打扰 → 伴侣菜单"勿扰"或关"主动智能 V2"。
5. 隐藏能力如需启用，在设置/指令中心切换对应 flag（注意部分需密钥）。
