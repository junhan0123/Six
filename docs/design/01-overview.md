# 01 · 概念拆解：贾维斯到底是什么

很多人以为"贾维斯 = 一个很聪明的 AI 模型"。这是最大的误区。
电影里的贾维斯，本质是 **一个把多种能力缝在一起的系统**，大模型只是其中"脑子"那一块。

把贾维斯拆开，其实是这 6 层能力。你想做哪一层，就决定你工程量的大小。

---

## 一、感知层（Perception）—— 它怎么"听"和"看"

- **语音唤醒（Wake Word）**：喊一声"贾维斯"才开工，否则一直静默省资源。
- **语音识别（ASR / STT）**：把你说的话转成文字。
- **视觉（可选）**：摄像头 + 图像理解，认人、看环境、读屏幕。
- **其他传感器**：温度、位置、心率（这点跟你规划的健康 APP 天然契合）。

> 中文坑点：通用英文方案（Whisper base）对中文口音、专有名词（比如"打开健康中枢"）识别一般。**FunASR（阿里达摩院）中文效果明显更好**，且能离线。

---

## 二、认知层（Cognition）—— 它怎么"想"

- **大模型推理**：理解意图、做规划、生成回答。这是"贾维斯本体"。
- **工具调用（Tool Calling / Function Calling）**：模型不会直接开灯，但它能"决定调用开灯函数"。这是从"聊天机器人"升级成"助手"的关键跃迁。
- **规划与反思（Planning & Reflection）**：复杂任务拆步骤、执行后自检。

> 关键认知：**贾维斯的"聪明" ≈ 70% 来自大模型 + 30% 来自工具编排**。
> 很多人卡在"模型不够聪明"，其实问题常出在"没给它合适的工具和信息"。

---

## 三、记忆层（Memory）—— 它怎么"记得你"

- **短期记忆**：当前这次对话的上下文（几轮内记得你刚说啥）。
- **长期记忆**：
  - 向量记忆（Chroma / Qdrant）：你说过的话、偏好、知识库，语义检索。
  - 结构化档案（SQLite / 用户画像 JSON）：你是谁、作息、过敏史、用药。
- **情景记忆**：过去发生的事、做过的决定。

> 对你（健康中枢方向）这层最重要：它能记住"你上周血压偏高、在吃 XX 药"，下次主动提醒。

---

## 四、行动层（Action）—— 它怎么"动手"

- **设备控制**：灯、空调、门锁、音箱（Home Assistant 是开源标杆）。
- **系统自动化**：发邮件、定日程、跑脚本（n8n 可视化编排）。
- **外部 API / 数据**：天气、日历、健康穿戴数据、联网搜索。
- **标准接口 MCP**：把上面这些统一成"工具总线"，模型即插即用。

---

## 五、人格层（Persona）—— 它怎么"有性格"

- **语气与风格**：干练？温柔？毒舌？写进 system prompt。
- **主动性（Proactivity）**：不是你问才答，而是"你今晚还没喝水，要提醒吗"。
- **边界感**：知道什么该做、什么要先问你。

> 这一层是"像贾维斯"和"像 Siri"的分水岭。技术上不难（靠 prompt + 规则），但最见功力。

---

## 六、交互层（Interface）—— 它怎么"出场"

- **语音输出（TTS）**：合成声音回答你。想要"贾维斯嗓音"可用 GPT-SoVITS 克隆音色。
- **可视界面**：桌面悬浮窗 / 网页聊天 / 全屋屏（类似 Echo Show）。
- **移动端 / 可穿戴**：手机 App、手表——跟你规划的健康 APP 打通。

---

## 难度与工程量速览

| 能力 | 难度 | 1 人可行性 | 建议优先级 |
|------|------|-----------|-----------|
| 语音对话（唤醒+ASR+LLM+TTS） | ⭐⭐ | ✅ 1~2 周 | 先做 |
| 记忆（向量+画像） | ⭐⭐ | ✅ 1 周 | 早期加 |
| 工具调用（MCP） | ⭐⭐⭐ | ✅ 1~2 周 | 早期加 |
| 设备自动化 | ⭐⭐⭐ | ✅ 有硬件即可 | 中期 |
| 视觉/多模态 | ⭐⭐⭐⭐ | ⚠️ 看需求 | 中后期 |
| 主动智能/人格 | ⭐⭐⭐ | ✅ 偏设计 | 持续打磨 |
| 移动端/可穿戴联动 | ⭐⭐⭐⭐ | ⚠️ 跨端工程 | 后期 |

---

## 一句话总结

> **贾维斯 = 一个大模型（脑子） + 一套工具编排（手脚） + 一份长期记忆（记性） + 一个性格设定（灵魂） + 一套语音/界面（外表）。**
> 你不用发明任何零件，只要会"组装 + 调校"，就能做出属于自己的版本。
