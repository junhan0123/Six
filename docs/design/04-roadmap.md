# 04 · 实施路线图：分 6 期，从 MVP 到全屋主动智能

核心原则：**每期都能跑、都能用，别憋大招**。先有"能听会说的助手"，再一层层叠能力。
以下工期按"一个人、业余时间"估算，全职可大幅压缩。

---

## 第 0 期 · 语音对话 MVP（2~3 周）

**目标**：喊一声名字，它能听懂、能回答、能念出来。
**做的事**：
- 装 Ollama，拉 Qwen3-8B。
- openWakeWord 唤醒 + FunASR 识别 + LLM 回答 + Edge-TTS 念出。
- 简单 CLI / Tkinter 窗口显示状态（监听/思考/说话）。
**产出**：本地可运行的"会聊天的贾维斯"。
**验收**：离线状态下，"贾维斯，现在几点"能正确回答并念出。

> 脚手架：直接基于 My-Xiao6 / Edge-Voice-Agent 改，替换中文零件。

---

## 第 1 期 · 记忆 + 工具调用（2~3 周）

**目标**：它记得你说过的话，能调工具办事。
**做的事**：
- 接 Chroma 向量记忆 + SQLite 用户画像。
- 用 LangGraph 接入 **MCP 工具总线**：先做 2~3 个工具（查时间/天气、记笔记、定日程）。
- 对话历史持久化。
**产出**：有记性、能办事的助手。
**验收**："记住我过敏原是花生"→ 下次问"我能吃这个吗"能结合记忆回答。

---

## 第 2 期 · 自动化与设备控制（3~4 周）

**目标**：能动手控制真实世界。
**做的事**：
- 部署 Home Assistant，接灯/空调/门锁等。
- 写 MCP Server 把 HA 设备暴露成工具。
- 用 n8n 编排复杂自动化（"我回家"→开灯+播报）。
**产出**：声控 + 自动化的家居助手。
**验收**："贾维斯，我回来了"→ 灯亮、空调开、播报今日日程。

---

## 第 3 期 · 多模态与视觉（3~4 周，可选）

**目标**：它能"看"。
**做的事**：
- 接摄像头 + Qwen-VL / InternVL 做视觉理解。
- 屏幕理解（截图→VLM），参考 Open Interpreter。
- 人脸识别（可选，注意隐私合规）。
**产出**：能看环境、读屏幕的助手。
**验收**："贾维斯，屏幕上这个按钮是干嘛的"→ 正确描述并操作。

---

## 第 4 期 · 主动智能与人格（持续，2~3 周打底）

**目标**：它不等你问，会主动关心；且有鲜明性格。
**做的事**：
- 主动规则引擎：定时检查条件（久坐、未喝水、日程冲突）触发提醒。
- 人格调校：system prompt + `personality.json`，定义语气/边界。
- 音色定制：CosyVoice / GPT-SoVITS 克隆"贾维斯嗓音"。
**产出**：有灵魂、会主动的助手。
**验收**：下午你久坐 1 小时，它主动说"起来走走？"。

---

## 第 5 期 · 移动端 + 健康中枢联动（4~6 周）

**目标**：打通你规划的健康 APP，成为真正的"健康副驾"。
**做的事**：
- 健康穿戴数据经 MCP 进贾维斯（心率/睡眠/血压）。
- 异常检测→主动干预（"心率偏高，要测血压吗"）。
- 移动端（融入健康 APP）或常驻桌面（Tauri）。
- 多端同步（PostgreSQL + 云端兜底）。
**产出**：贾维斯 = 健康中枢的智能入口。
**验收**：手表测到夜间心率异常 → 早晨贾维斯主动汇报并给建议。

---

## 工作量与风险总览

| 期 | 工期(业余) | 难点 | 风险 |
|----|-----------|------|------|
| 0 | 2~3 周 | 中文 ASR 调通 | 麦克风/权限 |
| 1 | 2~3 周 | 记忆检索质量 | 噪声记忆 |
| 2 | 3~4 周 | 设备协议对接 | 硬件成本 |
| 3 | 3~4 周 | 视觉延迟 | 隐私合规 |
| 4 | 持续 | 主动性不扰民 | 过度打扰 |
| 5 | 4~6 周 | 跨端同步 | 工程量大 |

**总工期**：业余约 5~8 个月到"像样"；全职约 3~4 个月出完整版。

---

## 给老板的 3 条实操建议

1. **今天就开干第 0 期**：clone 一个 xiao6 开源项目，2 周内你就能跟它对话。成就感驱动后续。
2. **中文零件优先**：FunASR + CosyVoice + Qwen，别在英文方案上死磕中文。
3. **把它做成健康 APP 的"语音大脑"**：不另起炉灶，复用你已有的健康中枢规划，贾维斯就是"阿枢"的具象化。

## 最小可用代码骨架（伪结构）

```
xiao6/
├── wake.py          # openWakeWord 监听
├── asr.py           # FunASR 识别
├── brain.py         # Ollama LLM + LangGraph 编排
├── memory.py        # Chroma + SQLite
├── mcp_server/      # 自定义工具(MCP)
├── tts.py           # CosyVoice / Edge-TTS
├── persona/         # personality.json + user_profile.json
└── ui/              # React 前端 / Tauri 桌面
```

打开 `architecture-diagram.html` 可看可视化全景。
方案全部文件见同目录 `README.md`。
