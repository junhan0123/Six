## B 期 · 动手能力（核心）

### B1 — 工具总线 + 本地执行器
**机制**：前端把对话发给 `server.py` → server 调 Agnes（带 `tools` 声明）→ 若 Agnes 返回 `tool_calls`，server 在**本地**执行对应工具 → 把结果回填给 Agnes → 生成自然语言回复 → SSE 流式返回前端。

**首期工具清单**（轻量、无外部依赖优先）：
| 工具 | 能力 | 执行点 | 风险 |
|------|------|--------|------|
| `get_time` | 当前日期/时间/星期 | 本地 | 无 |
| `calculator` | 数学表达式计算 | 本地（安全 eval 沙箱） | 低 |
| `note_save` | 保存笔记/待办 | 本地 SQLite | 无 |
| `note_list` | 列出笔记/待办 | 本地 SQLite | 无 |
| `open_app` | 打开本地程序/文件 | 本地 subprocess | **高→需 UI 二次确认** |
| `web_search` | 联网搜索（可选） | 需搜索 API Key | 中 |
| `weather` | 天气查询（可选） | 需天气 API Key | 低 |

**安全设计**（重要）：
- `open_app` 等危险操作：server 不直接执行，而是向前端发 `need_confirm` 事件，UI 弹出"确认执行？"按钮，用户点确认后 server 才执行。
- 所有工具调用在遥测面板实时显示（工具名 + 入参 + 结果），透明可审计。

**UI 变更**：
- 工具执行期间，核心球显示「执行中」状态 + 工具名浮层。
- 危险操作弹确认框。

### B2 — 长期记忆
- SQLite 存储：对话历史、用户画像（称呼/偏好）、笔记/待办。
- 会话启动时加载最近 N 轮上下文 + 用户画像，注入 system prompt。
- 记忆摘要：长对话自动压缩，避免 token 爆炸。

## C 期 · 语音

### C1 — 语音输出 TTS（最快见效，不依赖麦克风）
- 方案：**Edge-TTS**（微软，中文自然、免费、纯 Python `pip install edge-tts`、联网即可）。
- 后端新增 `POST /api/speak`：接收文本 → 生成 mp3 → 返回音频或前端用 `<audio>` 播放。
- UI：
  - 每条 Xiao6 回复带「🔊 朗读」按钮（规范上用 SVG 图标，不用 emoji）。
  - 顶部开关「自动朗读」，开启后每次回复自动念出。
- 备选：CosyVoice 本地（需 GPU + 模型下载，效果更好但重，放后期）。

### C2 — 语音输入 ASR（待你确认麦克风）
- 麦克风采集：`sounddevice` / `pyaudio`。
- 识别：**FunASR**（中文优先，本地跑，RTX 4060Ti 可胜任；需 `pip install funasr modelscope` + 下载模型）。
- 备选：Whisper（中文弱于 FunASR，不优先）。
- UI：「按住说话」按钮 → 录音 → ASR → 填入输入框 → 发送。
- **无麦克风兜底**：支持"上传音频文件"喂给 ASR，验证链路。
- 进阶：唤醒词（openWakeWord）、全双工语音对话闭环。

## D 期 · 主动智能与人格（✅ 已完成 2026-07-26）
**机制（纯本地实现）：**
- **TICK 心跳主线程**：每 15s 轮询到期提醒（`reminders` 表），到点主动推送，不依赖用户发起。
- **主动推送通道**：`GET /api/stream` 用 SSE 长连接（`protocol_version=HTTP/1.1` keep-alive），服务端维护订阅者队列，向所有在线客户端广播 `xiao6_proactive` 事件；离线期间产生的消息落 `pending_proactive`，客户端重连即补推。
- **每日简报（ACI 预判注入）**：每日首次连接时主动播报日期 + 待提醒数 + 笔记数（模板生成，不耗 Agnes 额度）；`build_context_prefix()` 每次对话前预取「当前时间 + 待办提醒」注入 system prompt，模型"睁眼即拿到"。
- **提醒工具**：`reminder_set`（中文时间解析：立刻/现在/N秒/N分钟/N小时/今天·明天 HH:MM/N点）+ `reminder_list`；`detect_intent` 关键词兜底。

**前端**：`EventSource('/api/stream')` 接收推送 → 渲染带「主动 · 提醒/每日简报」标签的 Xiao6 气泡（打字机 + 自动朗读）；记忆面板新增待办提醒列表。

**验收（e2e_d.py）**：每日简报推送 ✅ / 到期提醒 TICK 推送 ✅ / ACI 含当前时间 ✅ / 提醒入库 ✅。
