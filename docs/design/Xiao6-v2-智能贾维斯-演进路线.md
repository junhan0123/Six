## 一、目标定义：什么是「智能贾维斯」

小6要从「能对话、能记事、能提醒的个人副驾」进化为「**常驻、主动、多模态、能替你干活的智能贾维斯**」。

与「聊天机器人」的本质区别（五个维度）：

| 维度 | 聊天机器人 | 智能贾维斯（目标） |
|------|-----------|------------------|
| 触发 | 被动：你来找它 | **主动**：它感知时机来找你 |
| 存在 | 按需：打开才有 | **常驻**：后台 ambient 运行 |
| 模态 | 纯文字 | **多模态**：语音 + 视觉 + 文本 |
| 角色 | 回答者 | **执行者**：能调动工具干活 |
| 认知 | 无状态 | **懂你**：长期记忆 + 人格一致 |

## 二、成熟度模型（L0 → L5，可衡量进度）

- **L0 命令行/网页聊天**（已越过）
- **L1 个人副驾**：记忆 + 主动提醒 + 多端同步 + 知识 RAG（**当前 ≈ L1**，Phase 1–6 落地）
- **L2 常驻语音副驾**：唤醒词 + 语音优先 + 可打断（→ Phase 8）
- **L3 环境感知副驾**：日历/应用/屏幕上下文 + 情境主动建议（→ Phase 9）
- **L4 自主执行副驾**：长任务 autonomous 循环 + 工具可靠 + 自我修正（→ Phase 10）
- **L5 智能贾维斯**：全息 HUD + 跨端无感 + 人格一致 + 反思自进化（→ Phase 11–13）

## 四、阶段路线图

### P7-4 · 部署打包（收尾，不阻塞后续）
- 出 `portable` 绿色版 + `nsis` 安装版（electron-builder 已配置）。
- 后端崩溃自动重启（退避）+「后端掉线」前端提示。
- 结构化日志写文件（带时间戳/级别，供打包后排错）。
- 离线能力确认 + 边界文档。
- **可选**：是否把 portable Python 打进包（见下「关键权衡」）。

### Phase 8 · 常驻语音副驾（Voice-first JARVIS）⭐ 贾维斯感最强的一步
- **P8-1 唤醒词**：集成 `openwakeword`（零密钥、本地模型），默认关、可开关；唤醒后进入聆听。
- **P8-2 语音优先模式**：全屏/迷你语音界面，TTS 流式输出（边生成边读），打断去抖优化。
- **P8-3 ASR 低延迟调优**：faster-whisper 尺寸/线程自适应；弱网/离线兜底 Vosk 路径。
- 验收：说唤醒词 → 聆听 → 对话 → 打断，全程本地可跑；`FEATURE_WAKE_WORD` 门控。

### Phase 9 · 环境感知副驾（Ambient Awareness）
- **P9-1 本地日历/日程**：读取 `.ics` / 本地 ical（零密钥），融入简报与主动建议。
- **P9-2 应用焦点感知**：Electron/系统辅助获知当前活动窗口（隐私门控，默认关）。
- **P9-3 屏幕文本上下文**（可选）：按需 OCR 抓取屏幕文本（强隐私开关，默认关）。
- **P9-4 主动建议引擎升级**：结合时间/位置/日历/活动，推「现在该做 X」类建议。
- 验收：关 → 零数据外泄；开 → 建议明显更「懂当下」。

### Phase 10 · 自主执行副驾（Agentic Core）⚠️ 分水岭
- **P10-1 长任务 autonomous 循环**：目标拆解 → 逐步执行 → 校验 → 汇报（复用 Goal/Task + tools）。
- **P10-2 工具可靠性 + 自我修正**：失败重试/换路；执行异常自动诊断。
- **P10-3 子任务委托**：轻量子 agent（本地，零密钥），并行处理独立子任务。
- **P10-4 工作流录制/回放**：把重复操作录成 Skill，一键复用。
- 验收：给一个多步任务，小6能自主跑完并汇报，中途卡住会自救或明示。

### Phase 11 · 全息视觉 HUD（Immersive HUD）
- **P11-1 常驻环境光环/波形**：Three.js 轻量常驻（CPU/GPU 预算内），反映聆听/思考/说话态。
- **P11-2 情境 glance 卡**：一句话状态（如「3 个待办、2 个会议、天气转雨」）常驻一角。
- **P11-3 可选 3D 助手场景/化身**：沉浸式对话场景（性能门控，可关）。
- 验收：60fps、不拖慢主进程、可一键隐藏。

### Phase 12 · 记忆与人格深度（Memory & Persona）
- **P12-1 反思循环**：定期蒸馏记忆 → 更新用户模型（兴趣/习惯/偏好）。
- **P12-2 人格一致性调优**：本地 persona 源迭代，语气/边界稳定。
- **P12-3 情感联结**：记住重要日期/语气偏好，表达有温度。
- 验收：跨会话人格稳定，Long-term 越用越「懂你」。

### Phase 13 · 无处不在（Omnipresence）
- **P13-1 移动/Web 伴随端**：手机可看简报、收提醒、轻量对话。
- **P13-2 跨端接力**：手机开口 → 桌面继续（device-client 同步已具备基础）。
- **P13-3 常驻伴随模式**：后台轻量运行，资源预算内常开。
- 验收：任意端唤醒，上下文无缝延续。

## 五、执行纪律（沿用 v2 最高权威）

- 纯本地 git，小步提交、确认后入库；不推翻 Phase 1–3 架构。
- 新增能力默认开、`FEATURE_*` flag 门控、可瞬切。
- **零密钥优先**：语音/本地 ASR/本地模型/本地感知一律零密钥可做；云大模型、微信飞书等渠道、在线地图等**单列**，用户配密钥再启。
- 前端改动后 **bump `index.html` 的 `?.js?v=` / `?.css?v=`**；重启 Electron + Ctrl+F5 强刷生效。
- **隐私优先**：所有感知/常驻能力默认关、强开关、可审计；绝不强采。

## 六、关键权衡（需你拍板）

1. **Python 是否打进包**：
   - 打 → 包 +~50MB，任意 Win 机双击即跑、零依赖（推荐 `portable` 版）。
   - 不打 → 包小，但目标机须预装 Python 3.11 + vosk + edge_tts。
   - 建议：默认打 portable Python，出 portable + nsis 双产物。
2. **感知能力默认关**：P9 的环境感知涉及隐私，默认关 + 明确开关，绝不静默采集。
3. ** autonomous 边界**：P10 自主执行默认限制在高授权场景，敏感操作仍要你确认。
