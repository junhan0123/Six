# Xiao6 界面 · 分阶段完善计划（慢工出细活）

方向已定：**先有一个非常好看、能真正对话的界面，再一步步加能力**。
大脑固定用 **Agnes API（云端）**，Ollama 本地模型暂不在本期范围。
每期都"可运行、可看、可聊"，不憋大招。

---

## 阶段 A · 视觉界面（本期已完成 ✅）

**目标**：一个惊艳的 HUD 指挥中枢 + 真实对话。
**已交付**：
- Retro-futuristic HUD 界面（玻璃面板 / 四角括弧 / 扫描线 / 核心球）
- 流式对话（SSE），Agnes 实时回字
- 核心球状态机（待命 / 思考中 / 回应中）
- 遥测面板（延迟 / Tokens / 轮次 / 人格 / 记忆）
- 本地代理 `server.py`，密钥仅存服务端

**验收**：打开 http://localhost:8000，能流畅对话且界面好看。

---

## 阶段 B · 工具与记忆（下一步）

**目标**：它会"办事"和"记得你"。
- 工具层：时间、计算器、笔记（"记一下…"）、网页搜索桩 —— 用代码侧意图路由（稳定，不依赖模型 tool 支持）。
- 记忆层：对话历史持久化（JSONL）+ 长期记忆面板在右侧展示。
- 人格强化：`personality.json` + `user_profile.json` 可视化编辑。

**验收**："记住我明早 9 点有会" → 之后问"我明天有安排吗"能答上。

---

## 阶段 C · 语音（让它能听会说）

**目标**：像电影里那样开口对话。
- 唤醒词：openWakeWord（可训练"阿枢 / Xiao6"）。
- 语音识别：FunASR（中文首选）。
- 语音合成：Edge-TTS / CosyVoice，核心球随语调"呼吸"。
- 麦克风按钮接真实输入；无麦克风时仍可文字。

**验收**：喊名字 → 说话 → 它听懂并念出回答。

---

## 阶段 D · 主动智能与人格打磨

**目标**：它不等你问，会主动关心；且有鲜明性格。
- 主动规则引擎：久坐提醒、日程冲突预警、夜间健康异常播报。
- 语音克隆：CosyVoice / GPT-SoVITS 定制"贾维斯嗓音"。
- 细节动画与音效打磨，沉浸感拉满。

**验收**：下午久坐 1 小时，它主动说"起来走走？"。

---

## 阶段 E · 全屋 / 桌面 / 健康中枢联动

**目标**：成为你"健康中枢 APP"的智能入口（即"阿枢"具象化）。
- Tauri 打包常驻桌面悬浮助手。
- 健康穿戴数据经 MCP 进 Xiao6，异常主动干预。
- 多端同步（PostgreSQL + 云端兜底）。

**验收**：手表测到夜间心率异常 → 早晨 Xiao6 主动汇报并给建议。

---

## 节奏建议

- 每期之间**先让你看效果、提意见**，再进入下一期，避免方向跑偏。
- 阶段 A/B 可快速迭代（纯前端+Python）；C/D 需要硬件（麦克风）配合。
- 所有代码持续放在 `G:\Xiao6\xiao6-ui\`，不另起炉灶。
