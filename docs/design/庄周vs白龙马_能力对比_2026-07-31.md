## 一、本轮补齐的 7 项（原 🔴 架构级缺口 → ✅）

| 能力 | 原状态 | 现状态 | 实现要点 |
|---|---|---|---|
| KWS 唤醒 | ❌ | ✅ | `kws.py` + `POST /api/kws`（短音频转写+唤醒词模糊匹配）+ 设置项开关 + 前端常驻低功耗聆听（命中唤醒词触发语音对话）；默认关闭，需用户手势开启 |
| 成果审视分身 | ❌ | ✅ | `review_clone.py`：以 LLM 批判视角审视小6回答（事实/逻辑/表达/改进）；工具 `review_output` + 可选自动审视（`XIAO6_AUTO_REVIEW`） |
| 地图服务 | ❌ | ✅ | `map_service.py`：内置 30 城 WGS-84 坐标 + haversine 距离 + 城市列表；离线合规，**不绘国界/瓦片**；工具 `map_query` + 前端 `map.js` 文字/坐标卡片面板 |
| 文档面板 | ❌ | ✅ | `doc_panel.py` + `GET /api/doc`：浏览/读取本地文档（md/txt 优先，pdf 元信息优雅降级），`_safe_join` 防路径穿越；前端 `doc.js` 列表+阅读面板 |
| 记忆审计 UI | ❌ | ✅ | `memory_audit.py` + `GET /api/memory_audit`：聚合对话历史/笔记/人物卡统计与抽样，可按保留天数清理（默认不删，有整表护栏）；前端 `memory-panel.js` |
| 多 LLM Provider | ❌ | ✅ | `llm.py` 抽象 `_provider_creds`：`agnes` 主用 + 可插拔 `llm2`（OpenAI 兼容）；`ACTIVE_LLM` 一键切换，经 `/api/config` 持久化 |
| 自适应心跳 | ❌ | ✅ | `proactive.py`：TICK 间隔随用户近期活跃度自适应（刚活跃 10s / 近期 20s / 空闲回落基础 30s），保留哨兵/限流/到期提醒优先级 |

## 三、小6反超白龙马的项

- VAD 打断续接（说话即打断朗读并续接，白龙马无）
- 本地语义 RAG（bge ONNX 向量召回，零云依赖）
- 13 类 Scene 声明式卡片体系
- 哨兵协作式单轮降级（非强杀线程）
- Context Engine 记忆架构（Phase 1 主路径切分）
- 离线 ASR 全链路（无 ffmpeg 依赖，16k WAV 直喂 whisper/Vosk）
- 多 LLM Provider 可插拔（agnes + llm2）
- 每日主动简报（天气 + 热点 + 待办聚合推送）
