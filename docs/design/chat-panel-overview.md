# 聊天窗口 hover 自动滑出 — 改动摘要

## 完成内容
参考白龙马 Cognitive Surface 的交互方式，将小6的聊天消息区从主区 stage 中移出，改为**右侧可隐藏面板**：
- 默认隐藏，鼠标移到屏幕右侧触发条时平滑滑出
- 鼠标离开面板/触发条后延迟 900ms 自动收回
- 提供「固定」按钮（图钉），固定后面板常驻不自动隐藏

## 改动文件
- `index.html`：移除 stage 内 `#messages`，新增 `#chatPanel` + `#chatTrigger`
- `styles.css`：新增 `.chat-panel` / `.chat-trigger` / `.chat-panel-pin` 样式与动画
- `app.js`：新增 hover 显示/隐藏逻辑、固定按钮逻辑，并将 `scrollDown()` 改为滚动消息面板内部

## 交互说明
1. 屏幕右侧会有一条极淡的青色细线（触发条），鼠标放上去右侧会滑出「对话记录」面板。
2. 面板内展示完整聊天记录，可滚动。
3. 点击面板右上角的图钉可「固定」，再次点击取消固定。
4. 底部输入坞保持常驻，仍可随时打字或点语音按钮。
