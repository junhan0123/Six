# Knowledge Ranking Model — Xiao6 v1.3

> 知识排序模型 | Project Intelligence System v1.3 · Phase 8
> 任务等级：LONG RUNNING KNOWLEDGE INTELLIGENCE FOUNDATION TASK
> 纪律：仅定义多维权衡维度与公式概念；**不实现评分**、不引数据库、不修改代码。

---

## 1. 目的

Phase 6 §3.6（Context Assembly）与 Phase 7 §3（融合）都需一个**排序依据**。本 Phase 定义 KU 的多维排序模型，使「哪些知识优先进入上下文、截断时留哪些」有可解释的规则。

> ❗ **最高纪律**：本 Phase **不实现任何评分计算**，不维护 usage 计数、不建评分服务。仅定义维度、权重方向与公式形态，供未来实现期落地。当前知识排序仍靠人工/约定 + Phase 4 权威等级。

---

## 2. 五维模型

| 维度 | 含义 | 数据来源 | 方向 |
|------|------|----------|------|
| **Authority (A)** | 权威等级 | Phase 4 L100–L30 | 越高越好 |
| **Relevance (R)** | 与请求的匹配度 | Phase 6/7 检索信号 | 越高越好 |
| **Freshness (F)** | 时效性 | Phase 3 `updated`/`version` | 越新越好（但有上限） |
| **Usage (U)** | 历史被引用频次 | 未来实现期统计 | 越高越好（防滥用） |
| **Dependency (D)** | 被其它高权 KU 依赖度 | Phase 5 `derived_from`/`supersedes` 入度 | 越高越该保留 |

---

## 3. 公式形态（概念）

```
score(KU) = α·A_norm + β·R + γ·F + δ·U + ε·D
约束：α > β ≈ γ > δ ≈ ε，且 α+β+γ+δ+ε = 1
```

- **A_norm**：Phase 4 `authority_prior`（L100=1.0 … L30=0.25），已是 0–1。
- **R**：检索相关度 0–1（Phase 6/7）。
- **F**：`1 / (1 + Δdays/τ)`，τ 为衰减常数（概念，如 180 天）；但 **F 不得推翻 A**（见 §4）。
- **U**：归一化引用频次 0–1（未来统计）。
- **D**：入度归一化 0–1（Phase 5 图）。

> 权重为**设计建议**：权威主导（α 最大），相关/新鲜次之，使用/依赖为微调。实际值实现期调参。

---

## 4. 关键约束（防反模式）

1. **权威不可逆**：`A` 为硬先验（Phase 7 §4），F/R 升高**不得**使 L30 超过 L100。即 `A` 作为乘子或阈值门，不参与简单加权竞争。
2. **禁止时间优先**：F 只表达「同权威内谁更新」，绝不因新而提权（继承 Phase 4 §3.2）。
3. **截断保底**：上下文预算截断时，**FROZEN 基线 KU（L100/L90 红线/事实）始终保留**，其余按 score 截取 Top-K。
4. **Dependency 保底**：被高权 KU `derived_from` 的源 KU 不得因低 R 被截掉（解释链完整）。

---

## 5. 与 Phase 7 融合的关系

- Phase 7 的 `score_hybrid` ≈ 本模型的 **R + D +（未来 Semantic）**。
- 本模型在其上**叠加 A（权威先验）与 F（新鲜度）**，形成最终 `score`。
- 二者是同一排序问题的两层：Phase 7 管「召回信号融合」，本 Phase 管「最终排序分」。
