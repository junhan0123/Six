# 09 — Local First Infrastructure（本地优先基础设施）

> 依赖：01（分层 L9）、02/03（数据落盘）、P11–P15
> 红线：用户数据/记忆/知识默认本地；云端仅计算，不得成为状态所有者。

---

## 1. 设计目标

Local First 是 AI OS 的**地基原则**，不是功能开关。它要求：全部用户数据、记忆、知识默认落盘本地；云端 LLM/嵌入仅作为"计算能力"被调用；系统在无网、无云时仍可运行核心能力；可选同步由用户显式控制，且不改变"本地为真相源"的地位。

---

## 2. 五大支柱

| 支柱 | 含义 |
|------|------|
| 数据驻留 | 记忆/知识/目标/状态存本地（SQLite + Vault + 文件） |
| 离线降级 | 云模型/云嵌入不可用时，本地模型/本地缓存接管 |
| 无硬云依赖 | 无云账号也能完成核心闭环（OS 不"向云报到"） |
| 可选同步 | 跨设备同步用户主动开启，端到端加密，本地优先合并 |
| 隐私即架构 | 隐私由系统结构保证，而非"信任厂商" |

---

## 3. 数据驻留与持久化

- Memory（02）：L1–L10 落本地 SQLite；语义索引 `mem_vectors` 本地。
- Knowledge（03）：Vault 为本地 `.md` 文件；Backend 索引本地。
- Goal/Workflow（04/05）：状态快照本地，支撑崩溃恢复（P15）。
- 凭据：本地密钥库（OS keychain / 加密文件），不落明文、不上云。

---

## 4. 离线降级（Offline Degradation）

```
                    ┌─────────────┐
   能力请求 ──────▶ │ 本地模型?   │ ──是──▶ 本地推理（离线可用）
                    └─────┬───────┘
                          │ 否
                    ┌─────▼───────┐
                    │ 云端模型?   │ ──是──▶ 云端推理（结果本地缓存）
                    └─────┬───────┘
                          │ 否（无网）
                    ┌─────▼───────┐
                    │ 降级模式     │ ──▶ 仅本地记忆/知识/规则可用
                    └─────────────┘
```

- 模型可云，但**必须提供本地降级路径**（本地小模型或规则回退）。
- 嵌入：本地优先；云端嵌入结果本地缓存（见 02 §6、03 §5）。
- 离线时 Proactive/主动能力受限，但查询、记忆、知识导航照常工作。

---

## 5. 可选同步（User-Controlled Sync）

- 同步默认关闭；开启须经用户显式授权。
- 同步方向：本地真相源 → 加密上传；下载仅合并，不覆盖本地未同步变更。
- 冲突策略：**本地优先 + 显式冲突队列**（不静默覆盖用户本地数据）。
- 同步通道为"可选能力"，故障不影响本地使用（无硬云依赖）。

---

## 6. 隐私即架构（Privacy by Architecture）

- 用户内容不经过未授权第三方；云端调用仅传"计算所需最小上下文"。
- 所有外部动作（发信、写文件、调用 API）经 PermissionGuard（见 08）。
- 可审计：每次外部副作用留痕（Memory L10 Governance）。
- 数据可携带：Vault 是纯文本，随时可导出、可脱离本系统阅读。

---

## 7. 加密与崩溃恢复

- 静态加密：本地数据库/密钥库加密（用户口令或 OS keychain）。
- 崩溃恢复（P15）：快照机制依赖本地持久化；无云也能恢复（见 04 §7、05 §5）。
- 备份：本地快照 + 可选用户导出；不强制云端备份。

---

## 8. 接口（抽象）

```text
LocalStore.put(namespace, key, value)   → 本地持久化（加密）
LocalStore.get(namespace, key)          → 本地读取
Sync.push() / Sync.pull()              → 可选、用户触发、加密
Degrade.mode()                         → 返回当前 local/cloud/offline 能力
```

---

## 9. 红线

- 禁止将云端设为状态所有者（用户数据必须本地可重建）。
- 禁止无本地降级路径的"云-only"能力（破坏离线可用性）。
- 禁止静默云同步覆盖本地变更。
- 禁止明文落盘凭据。

> 目标态设计；实现由 Local First Sprint 承接，本 Sprint 不写代码。
