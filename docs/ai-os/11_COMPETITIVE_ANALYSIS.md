## 3. 真正的核心竞争力（Moat）

小6不可替代之处在于**四者的统一**，单一竞品只覆盖其一：

1. **Local First + 隐私架构**：数据本地真相源，云仅计算（vs 所有云优先大模型）。
2. **记忆 × 知识双引擎**：10 层记忆 + Obsidian 知识层，且知识是人类可读可拥有的（vs 所有"黑箱向量库"）。
3. **克制的主动智能**：薄层、可撤销、低打扰——别人要么没有主动，要么"自动执行吓人"（vs 自动 Agent 叙事）。
4. **OS 级执行内核**：单 Runtime 内 Goal→Workflow→Agent→Execution 形式化，权限门控 + 崩溃恢复（vs 单点工具）。

> 单点能力别人能做；**把它们收敛进一个本地优先 OS** 是小6的壁垒。

---

## 4. 必须做到世界级（World-Class）

- **记忆一致性**：跨会话/项目/时间，记忆不丢、不冲突、可蒸馏。
- **知识导航体验**：Obsidian 图谱 + RAG 融合，检索既准又可溯源。
- **执行安全感**：每一步动作可追溯、可撤销、敏感必确认，用户"敢放权"。
- **离线可用性**：无网时核心闭环（记忆/知识/本地模型）照常。
- **打扰克制**：Proactive 的打扰预算与可配置级别行业领先。

---

## 5. 绝不抄袭（What We Will NOT Copy）

- ❌ "无限自动执行 Agent"叙事——我们克制、可撤销（P13）。
- ❌ 把用户数据迁到云端换取"智能"——Local First 不可破。
- ❌ 黑箱知识库（塞进向量库无法阅读）——知识即文件（P12）。
- ❌ 多 Runtime / 多 Agent 进程拼凑——单 Runtime 角色切换（P14）。
- ❌ 无检查点、崩溃即丢目标的"脆弱执行"——必须可恢复（P15）。

---

## 6. 对竞品的姿态

| 竞品类 | 姿态 |
|--------|------|
| 通用大模型 | 借用其"推理能力"（云/本地模型），但不借用其"云持有数据"模式 |
| AI 编码工具 | 借鉴其工具调用体验，但纳入统一 Execution Channel 与权限 |
| 本地模型前端 | 借鉴其本地模型接入，但升格为 OS 的执行与记忆层 |
| Obsidian | 直接以 Vault 为知识真相源，补其缺失的 AI 主动与执行 |
| WorkBuddy 类多能助手 | 借鉴多能力，但坚持单 Runtime 与 Local First 不妥协 |

---

## 7. 结论

小6不与任何单点产品正面竞争，而是占据"**本地优先个人 AI 操作系统**"这一尚无强者占据的空白带。护城河来自架构纪律（单 Runtime / Local First / 可恢复），而非某个炫技功能。
