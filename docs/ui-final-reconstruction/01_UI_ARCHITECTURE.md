# 小6 AI OS · 最终界面 UI 架构说明

> 文件：`xiao6-ui/final/`  
> 设计基线：`1920×1080` 固定画布，`transform: translate(-50%, -50%) scale(var(--ui-scale))` 任意窗口保持 16:9 比例  
> 约束：不修改后端、不新增 Runtime、不发明数据、不制造 Dashboard

---

## 1. 设计目标

把「一个有很多面板的后台/聊天/仪表盘」变成「小6就在这里」。
核心不是信息陈列，而是**可感知的 AI 生命体**：一个被 8 种状态驱动的中央核心，被真实记忆/知识/目标/执行进度/语音状态环绕。

| 旧感觉 | 新感觉 |
|---|---|
| 打开一个网页/后台 | 进入小6 AI OS 主空间 |
| 功能卡片堆砌 | 一个核心 + 一片信息场 |
| 假数据/占位步骤 | 全部数字来自既有 API |
| 麦克风按钮只是装饰 | 真实 ASR/唤醒/TTS 链路 |

### 2.1 固定画布策略

- 设计尺寸永远为 `1920×1080`。
- `.stage` 以绝对定位居中，通过 `viewport-scale.js` 计算 `--ui-scale = min(w/1920, h/1080)`。
- `.stage { transform: translate(-50%, -50%) scale(var(--ui-scale)); }`
- 结果：任意窗口下宽高比锁定为 16:9，不会横向/纵向拉伸。

## 3. 数据流（单一方向）

```
后端 API  ──►  data-bridge.js  ──►  FinalState  ──►  所有组件
    ▲                              │
    └────────── SSE / 30s 轮询 ────┘
```

- `data-bridge.js` 只负责读取 7 个既有接口并归一化。
- `state.js` 持有唯一快照，提供 `subscribe/get/refresh`。
- 每个组件是快照的纯消费者，不直接请求 API。
- SSE 只订阅后端已发出的事件：`agent_state`、`wakeword_detected`。

## 4. 状态体系

### 4.1 Agent 8 态（权威来源：`../avatar-state.js META`）

| 状态 | 颜色 | 含义 | 面板行 |
|---|---|---|---|
| IDLE | `#5fb3c8` | 待命 | 在线待命 |
| WAITING | `#f0b35e` | 等待指令 | 等待指令 |
| THINKING | `#8b9bff` | 思考中 | 思考中 |
| PLANNING | `#c08bff` | 规划中 | 规划中 |
| EXECUTING | `#56d364` | 执行中 | 执行中 |
| COMPLETED | `#56d3a0` | 已完成 | 在线待命 |
| ERROR | `#ff6b6b` | 异常 | 异常 |
| OFFLINE | `#8a93a6` | 离线 | 离线 |

### 4.2 语音态

- `idle` / `listening` / `thinking` / `speaking` / `error`
- 优先于 Agent 状态：当语音在听时，面板显示「聆听中」。
- 真实麦克风电平驱动 AI Core 波形振幅。

## 5. 关键约束落实

| 约束 | 落地 |
|---|---|
| 不修改后端 | 只使用既有 `/api/*` 与 `/api/stream` |
| 不新增 Runtime | 与 Agent Runtime 仅通过 API/SSE 观察 |
| 不发明数据 | 无假步骤、无假进度；空态如实显示 |
| 不做 Dashboard | 单屏空间，无分页、无表格、无堆叠卡片 |
| 独立可回滚 | `final/` 完全独立，`_legacy/` 保留旧文件 |
