## 2. 未签名说明（必须公开披露）

**小6 v1.4.0 的 Windows 安装包与 Portable 包均未进行代码签名（Code Signing）。**

原因：当前无代码签名证书（未采购 Authenticode / EV 证书）。本版本以「个人本地 AI 助手」定位发布，暂不纳入签名成本。

影响：
- Windows SmartScreen 在下载/首次运行时可能提示 **「Windows 已保护你的电脑」/ 未知发布者**。
- 杀毒软件可能额外弹窗询问是否允许运行。

这**不影响程序功能与安全性**，仅为信任链缺失带来的系统提示。

## 3. SmartScreen 用户操作指引

当用户双击安装器/Portable 后出现 SmartScreen 拦截时，按如下步骤继续：

**情形 A — 安装器（`小6-Setup-1.4.0-x64.exe`）**
1. 出现蓝色 SmartScreen 对话框：「Windows 已保护你的电脑」。
2. 点击左下角 **「详细信息」**（或「更多信息」）。
3. 出现 **「仍要运行」** 按钮，点击它。
4. 继续正常安装流程（选择目录 → 下一步 → 完成）。

**情形 B — Portable（`小6-1.4.0-x64.exe`）**
1. 同上出现 SmartScreen 提示。
2. 点击 **「详细信息」→「仍要运行」**。
3. 程序直接启动（无需安装）。

**情形 C — 杀毒软件拦截**
1. 若被杀软隔离，进入杀软「隔离区/信任区」。
2. 将 `小6*.exe` 添加为**信任/排除项**后重新运行。

> 校验建议：运行前先用 §1 的 SHA-256 核对下载文件，确保与官方发布值一致，再执行上述「仍要运行」。
