# 小6 · 打包与部署（P7-4）

> Electron 壳 + 本地 Python 后端，产出可分发的桌面应用。
> 本文件随代码演进维护；构建步骤请在**桌面机（有 GUI、有 Python 3.11）**执行。

---

## 一、现状

- `electron/package.json` 已含 `electron-builder` 配置：`appId` `com.xiao6.desktop`、产品名「小6」、图标、`win` 目标 **portable（绿色版）+ nsis（安装版）**。
- `electron/main.js`：单实例锁、托盘、原生菜单、后端状态推送。
- `electron/src/backend-launcher.js`：端口占用检测、Python 自动探测、**崩溃自动重启（指数退避，上限 5 次）**、**结构化日志写文件**。
- 后端日志位置（打包后）：`<用户数据>/logs/xiao6-backend.log`。

---

## 二、一键出包

```bash
# 在桌面机（已装 Node + Python 3.11+vosk+edge_tts）
cd G:/xiao6/electron

# 依赖已安装可跳过；首次或换机需：
npm install

# 绿色便携版（无需安装，双击即跑，推荐先出这个验证）
npm run dist:portable

# 安装版（nsis，可改安装目录、建桌面快捷方式）
npm run dist
```

产物在 `electron/dist/`：
- `小6-<version>-<arch>.exe`（portable，单文件）
- `小6 Setup <version>.exe`（nsis 安装包）

> 注意：默认配置**不打包 Python**。目标机需自装 Python 3.11 + vosk + edge_tts，否则启动会报「找不到 python」。若要做到「零依赖绿色版」，见第三节。

---

## 三、（可选）打包 portable Python → 真正零依赖

让任意 Windows 机器双击即跑、无需预装 Python：

1. 准备一份 **portable CPython 3.11**（含 `vosk` + `edge_tts` 及其依赖）：
   - 复制 `python.exe` + `Lib/` + `site-packages/` + `DLLs/` 到一个干净目录，例如 `electron/resources/python/`。
   - 验证：`electron/resources/python/python.exe -c "import vosk, edge_tts, server"`（在 `xiao6-ui` 目录下）能通过。
2. 在 `electron/package.json` 的 `build.extraResources` 增加一项（JSON 不支持注释，直接加对象）：
   ```json
   "extraResources": [
     { "from": "../xiao6-ui", "to": "backend", "filter": ["**/*", "!__pycache__", "!*.db", "!*.log", "!node_modules", "!.env"] },
     { "from": "resources/python", "to": "backend/python" }
   ]
   ```
3. `backend-launcher.js` **已自动优先检测** `resources/backend/python/python.exe`，无需改代码。
4. 重新 `npm run dist:portable` → 产出的绿色版已自带 Python，零外部依赖。

> 代价：包体增大约 50–120MB（取决于 Python 体积）。取舍由产品形态决定。

## 五、排错

- **启动报「找不到 python」**：目标机未装 Python 3.11 全家桶，或未做第三节的 Python 打包。
- **后端起不来**：看 `logs/xiao6-backend.log`（结构化日志，含时间戳/级别）；崩溃会自动重启，达到 5 次后状态置 `failed` 并停止。
- **端口 8000 被占**：launcher 会直接连接已有后端，不重复拉起（适合开发时手动起 server）。
- **GUI 不显示**：检查 Electron 是否被沙箱/无显示环境限制（CI 无法验证 GUI，需在桌面会话运行）。
