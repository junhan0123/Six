# 小6 · 离线能力说明

> 适用范围：小6 v2 桌面端（Electron + 本地 Python 后端）
> 目的：明确「断网也能用」与「必须联网」的能力边界，便于在飞机/无网环境下预期行为。

---

## 一、核心结论

小6的**数据存储、记忆、检索、本地语音识别、知识向量**全部在**本机**完成，**不依赖外网**；
唯一强依赖网络的是**大模型对话本身（AGNES API）**——这是「会思考」的部分，断网后无法生成回答，但本地能力仍可正常记录与检索。

---

## 二、离线可用（断网照常工作）

| 能力 | 实现 | 离线说明 |
|------|------|---------|
| 记忆 / 情节记忆 / 用户模型 | SQLite + FTS5（`db.py`） | 完全本地，可写可读可检索 |
| 笔记全文检索 | FTS5 | 本地索引，离线可用 |
| 目标 / 任务系统 | `db.py` + Goal/Task | 本地持久化、进度聚合、到期提醒 |
| 知识 RAG（语义检索） | `embed.py` 本地 ONNX（BAAI/bge-small-zh-v1.5 量化版，~24MB，onnxruntime CPU） | **纯本地向量推理，零网络** |
| 本地语音识别（ASR） | Vosk 本地模型 / faster-whisper（small，本地） | 本地推理；faster-whisper 首次需经 hf-mirror 拉模型，拉过即离线可用 |
| 地图面板 | `map.js` 仅渲染坐标卡 | **无在线瓦片/CDN**，展示 LLM 给出的坐标信息，离线可用 |
| 本地日历（规划中 P9） | 读取本地 `.ics` | 设计即为离线优先 |
| 设置 / 主题 / 简报本地缓存 | `localStorage` + 本地 JSON | 离线可读写 |
| 数据导出 / 导入 | `data_manager.py` | 本地文件操作，离线可用 |

---

## 三、必须联网

| 能力 | 依赖 | 断网表现 |
|------|------|---------|
| **大模型对话 / 思考** | AGNES API（`/api/chat`） | 无法生成回答；前端显示「核心在线」但对话返回错误 |
| 语音合成（TTS）朗读 | 默认 `edge_tts`（微软云端） | 断网无法朗读；若配置本地 `sovits` TTS 后端可离线 |
| 天气 | open-meteo | 简报天气缺数据，其余不受影响 |
| 科技热点 | HackerNews | 简报热点缺数据，其余不受影响 |
| 在线地图 / 高德（如启用） | 高德 API + key | 需配置才启用，默认未开 |
| 云 ASR / 云 TTS / 媒体生成 | 各厂商 API + key | 默认未启用，需用户配密钥 |
| 微信 / 飞书 / Discord 渠道 | 各平台 API + key | 默认未启用 |

---

## 四、断网时的预期行为

- **能做的**：继续用文字/语音（ASR 本地）记录想法、查笔记、看记忆、管理目标、检索知识库、看地图坐标卡。
- **不能做的**：让小6「思考/回答」（需 AGNES）、听它朗读（默认 edge_tts）、获取实时天气/新闻。
- **不会崩**：后端健康检测、本地 DB、前端界面在断网下均稳定运行；仅网络类调用会失败并优雅降级。

---

## 五、让小6「尽量离线」的推荐配置

1. TTS 改为本地 `sovits`（需自备模型，配置 `TTS_BACKEND=sovits`）→ 朗读离线化。
2. 预拉取 faster-whisper 模型（经 `hf-mirror`）→ ASR 完全离线。
3. 简报中的天气/新闻在断网时自动跳过，不影响其余内容。
4. 知识库、记忆、笔记天然离线，无需额外配置。
